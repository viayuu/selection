### 10.3 实例特征的数学分析（偏好性导向）

**核心问题**：我们想知道不同方法在什么类型的实例上表现更好。

**简单来说**：
- 有的实例是"长条形"城市分布（比如沿公路）
- 有的实例是"聚团型"分布（比如几个城市集群）
- 不同方法可能对不同类型的实例有"偏好"

我们用 TSP 坐标计算一些简单的几何特征来描述每个实例的"长相"，然后分析：
1. 哪些特征与方法的表现相关？
2. 每个方法"喜欢"什么类型的实例？

---

#### 📊 特征名称速查表（按重要性和理解难度排序）

**必读特征（最容易理解）**：

| 特征名 | 一句话解释 | 为什么重要 | 取值范围 |
|--------|------------|------------|----------|
| `n` | 城市数量 | 城市越多通常越难 | 20~2000+ |
| `hull_fill` | 凸包填充率 | 越接近1 = 城市铺得越满；越接近0 = 越稀疏 | 0~1 |
| `grid_entropy` | 网格熵 | 越接近1 = 分布越均匀；越接近0 = 越聚团 | 0~1 |
| `bbox_aspect` | 长宽比 | 越大 = 越细长（像面条）；=1 = 正方形 | ≥1 |
| `pc_anisotropy` | 各向异性 | 越大 = 越接近一条线 | ≥1 |

**进阶特征（想深入理解时再看）**：

| 特征名 | 一句话解释 | 取值范围 |
|--------|------------|----------|
| `pc1_var_ratio` | 第一主轴占比 | 0.5~1，越接近1越像一条线 |
| `hull_ratio` | 凸包顶点比例 | 0~1，越大形状越不规则 |
| `compactness` | 紧致度 | =1是圆形，越大越不紧凑 |
| `nnd_mean_over_scale` | 最近邻距离均值 | 越小越密集 |
| `nnd_cv` | 最近邻距离变异系数 | 越大局部密度越不均匀 |

#### 📈 统计概念：5分钟速成

##### 1️⃣ 相关系数：两个东西"一起变化"的程度

**问题**：特征 X 与 gap Y 有关系吗？

**相关系数**（-1 到 +1 的数字）告诉你：
- **+1**：完全正相关（X↑ → Y↑，像正比例函数）
- **-1**：完全负相关（X↑ → Y↓，像反比例函数）
- **0**：没关系（X变化时Y随机）

**例子**：
- 相关系数 = **-0.8**：特征越大，gap 越小（这是好事，因为gap越小越好）
- 相关系数 = **+0.6**：特征越大，gap 越大（这是坏事）

**两种相关系数的区别**：

| 类型 | 问题 | 适用场景 |
|------|------|----------|
| **Pearson** | 是直线关系吗？ | 线性关系 |
| **Spearman** | 是单调关系吗？（一增一减） | 非线性但单调 |

**新手建议**：先看 Spearman（更稳健），再看 Pearson。

**图示理解**：
```
强正相关 (+0.9)          强负相关 (-0.9)           无相关 (0)
    y                         y                        y
    ↑                        ↑                        ↑
 10 |●●●●●●●              10 |                  10 |    ●●●
    |●●●●●●                |  ●●●●●●               | ●●●    ●
  5 |●●●●●●               5 |●●●●●●              5 |●  ●●●
    |●                     |●●                    |  ●●
  0 +------------> x      0 +------------> x     0 +------------> x
    0   5   10             0   5   10             0   5   10
```

##### 2️⃣ 热力图（Heatmap）：相关系数的可视化

**问题**：一堆数字看起来太累，怎么办？

**热力图**用颜色代表数字大小：
- 🔴 **红色**（正数）：正相关（特征越大，gap越大，越差）
- 🔵 **蓝色**（负数）：负相关（特征越大，gap越小，越好）
- ⚪ **白色**（接近0）：没关系

**读图步骤**：
1. 找你关心的方法（行）
2. 看这行里颜色最深的格子（红或蓝）
3. 那个格子对应的列（特征）就是这个方法最敏感的特征

**示例**：
```
              n    hull_fill    grid_entropy
elg     🔴 0.65  🔵 -0.45     ⚪ 0.05
lehd    ⚪ 0.20  🔵 -0.70     🔵 -0.30
omni    🔴 0.50  ⚪ -0.10     🔵 -0.40
```
- ELG 受城市数量 `n` 影响很大（红色越深 = 城市越多gap越大）
- LEHD 受凸包填充率 `hull_fill` 影响大（蓝色越深 = 越铺满越好）

---

##### 3️⃣ 难度 vs 可选择性：两个重要的实例级指标

**难度（avg_gap）**：
- 定义：所有方法在该实例上的平均gap
- 含义：越大 = 这个实例对所有方法都很难
- 类比：像"考试题难度"

**可选择性（std_gap）**：
- 定义：所有方法gap的标准差
- 含义：越大 = 不同方法差异大 = "值得做选择"
- 类比：像"学生成绩差距"，差距大说明分层明显

**为什么重要**：
- 难但不可选：所有方法都一样差 → 选哪个都一样
- 易但可选：都很好但差异小 → 选哪个无所谓
- 难且可选：差异大 → **选对方法收益最大**（这是我们要找的）

**例子**：
```
实例A: avg_gap=0.5%, std_gap=0.1%  → 容易，但没选择空间
实例B: avg_gap=3.0%, std_gap=0.2%  → 难，但没选择空间
实例C: avg_gap=1.5%, std_gap=1.0%  → 中等难度，高选择价值 ⭐
```

##### 4️⃣ Winner偏好画像：方法"喜欢"什么类型的实例？

**核心思想**：
把实例分成两组：
- **Win组**：该方法赢了的实例
- **非Win组**：该方法没赢的实例

然后比较两组的特征差异。

**Effect Size（效应量）**：
- 定义：两组特征均值差异的标准化度量
- 读法：
  - **正数**：Win组的这个特征倾向于更大
  - **负数**：Win组的这个特征倾向于更小
  - **绝对值大小**：
    - `|d| < 0.2`：很小（几乎没区别）
    - `0.2 ≤ |d| < 0.5`：小（有区别但不明显）
    - `0.5 ≤ |d| < 0.8`：中等（有明显区别）
    - `|d| ≥ 0.8`：大（区别很明显）

**例子**：
```
方法: LEHD
特征: hull_fill
Effect Size: +0.65
```
解读：LEHD赢的实例，凸包填充率明显更大（更"铺满"），说明LEHD"喜欢"铺满型的实例。

**P-value（显著性）**：
- 定义：随机产生这么大差异的概率
- 读法：越小越显著（不太可能是运气）
- 经验阈值：
  - `p < 0.05`：显著（通常说"有统计学差异"）
  - `p < 0.01`：非常显著
  - `p < 0.001`：极其显著

**注意事项**：
- 这里同时检验了20个特征，严格说需要校正（但作为探索性分析可以先不纠结）
- p-value小不代表效应量大（可能很显著但实际差异很小）

##### 5️⃣ PCA图：把高维特征压缩到2维来看

**问题**：我们有20个特征，怎么在一张图上显示？

**PCA（主成分分析）**的解决方案：
- 把20维特征"压缩"成2个主成分（PC1, PC2）
- 每个实例变成图上的一个点
- 点的颜色 = 谁赢了

**怎么读图**：

```
        PC2
         ↑
         |    ● ● ●     (红色 = LEHD的win区)
         |  ●   ●
         | ● ● ● ●
         +------------→ PC1
           ● ● ●
         | ●   ● ●     (蓝色 = ELG的win区)
         |   ● ●
```

**判断标准**：
- ✅ 如果不同颜色集中在不同区域 → 特征空间有可分结构，适合做选择
- ❌ 如果颜色混杂在一起 → 仅靠这些特征很难做选择

**PCA Loadings表**：
- 告诉你PC1、PC2主要由哪些特征决定
- 绝对值越大 = 该特征对这个主成分贡献越大

---

#### 🎯 总结：快速阅读指南

**当你看到相关系数表时**：
1. 先找绝对值最大的几个格子（颜色最深的）
2. 正相关（红色）= 特征越大，方法越差
3. 负相关（蓝色）= 特征越大，方法越好

**当你看到Winner偏好表时**：
1. 看Effect Size绝对值 > 0.5 的行（有明显偏好）
2. 正数 = 该方法"喜欢"大值
3. 负数 = 该方法"喜欢"小值
4. 结合p-value判断是否显著（<0.05）

**当你看到PCA图时**：
1. 如果颜色分区域 = 可以基于特征做选择
2. 如果颜色混杂 = 需要更多特征或换思路
