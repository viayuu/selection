## 整体流程

1. 输入实例
2. 初始化 从 initializer  里选一个方法
3. 调用该初始化器，得到初始解 sol_0
4. 进入固定长度 I 的 迭代；
5. 在每一步：
   - 根据“实例 + 当前解 + 迭代状态”编码当前状态；
   - 输出各个 operator 的 logits；
   - 选择一个 operator；
   - 对当前解执行一步改进，得到 sol_{t+1}
   - 更新当前解、历史最优解、停滞步数等状态
6. 结束后，用总改进来训练策略

## 状态表示

### 实例静态特征

- 做图编码；
- 用 Transformer encoder 建模点集之间关系
- 做max pooling，得到实例级 embedding

### 当前解局部特征

为 tour 上每个位置构造特征：

- 当前节点坐标；
- 后继节点坐标；
- 与前驱的边长；
- 与后继的边长。

### 当前解顺序特征

- 当前节点在 tour 中的归一化位置；
- cyclic positional encoding；
- 整条 tour 的边长统计量：mean / std / min / max。

### 迭代特征 去掉

- 当前已经迭代到第几步；
- 最近是否连续没有改进；
- 当前解相对初始解、相对历史最优解处于什么位置。
- 上一步 operator ID

- current_length / init_length
- best_length / init_length
- (current_length - best_length) / init_length

## 训练方式

batch mean baseline：

- baseline = mean(episode_return)

然后：

- advantage = episode_return - baseline
