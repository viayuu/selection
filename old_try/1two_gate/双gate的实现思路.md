整体前提：一个模型不可能适配所有的实例，模型肯定具有偏向性

原论文：
只有一个gate
把目前代表性的模型，搞一个上层的gate，让数据通过gate，根据数据选择模型
一对多的关系变成一对一的关系
是监督学习，因为它事先对每一个实例用每个model算出一个解，然后进行排序

论文的假设是：一个模型的pipline适用所有数据，但也不成立，因为数据分为初始化和迭代

我想要做的论文内容：
解决原论文的假设的不成立部分，即细化整个pipline
搞两个gate，把每个模型解耦，细化整个pipline
gate 1 选初始化, pomo/reld/lehd/指针网络 等，产生一个初始化的解
gate 2 选迭代，gate 1 的结果和 data 传到 gate 2 ，传统的2-opt/大规模搜索/rrc
要做的是学/训练 gate 1 和 gate 2
其实是一个多分裂问题
但n*m个可能性，太大了，因此不适用监督学习，所以要用强化学习，给奖励自己试错

补充：1. 强化学习用AC架构
 2. baseline的选择：用batch个实例的路径的均值，作为baseline
 3. 奖励函数就用score（即求解出来的长度）
 4. 计算loss的时候，不要忘记将上层模型（初始化）和下层模型（迭代）都考虑进loss function里
 5. 先不考虑时间，固定一个迭代次数、选迭代方式
