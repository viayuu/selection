## 二、TL-UCB 选择流程（每轮迭代的第一步）

```
                    TL-UCB 选择流程
                    (Algorithm 2, TL_UCB.m)
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │  第一层: 对4个高层臂计算UCB值           │
        │                                       │
        │  对每个模型 m ∈ {RBF, GP, PRS, KNN}:   │
        │                                       │
        │  UCB(m) = Q_H(m) + √(α·ln(t)/T_H(m)) │
        │           ───────   ─────────────────  │
        │           利用项      探索项             │
        │                                       │
        │  代码: U_model_value(i) = TL_UCB(...)  │
        └──────────────────┬──────────────────┘
                           │
                           ▼
        ┌─────────────────────────────────────┐
        │  选UCB值最大的高层臂                    │
        │  (并列则随机打破平局)                    │
        │                                       │
        │  代码: idx = find(max(U_model_value))  │
        └──────────────────┬──────────────────┘
                           │
              ┌────────────┼────────────┐────────────┐
              ▼            ▼            ▼            ▼
         idx=1:RBF    idx=2:GP    idx=3:PRS    idx=4:KNN
              │            │            │            │
              ▼            ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
        │第二层:    │ │第二层:    │ │第二层:    │ │第二层:    │
        │在关联的   │ │在关联的   │ │在关联的   │ │在关联的   │
        │低层臂中   │ │低层臂中   │ │低层臂中   │ │低层臂中   │
        │用UCB选择  │ │用UCB选择  │ │用UCB选择  │ │用UCB选择  │
        ├──────────┤ ├──────────┤ ├──────────┤ ├──────────┤
        │prescrn   │ │LCB      │ │prescrn   │ │L1-exploi │
        │  vs      │ │  vs     │ │  vs      │ │  vs      │
        │local src │ │EI       │ │local src │ │L1-explor │
        └────┬─────┘ └────┬────┘ └────┬─────┘ └────┬─────┘
             │            │           │             │
             └────────────┴───────────┴─────────────┘
                                 │
                                 ▼
                   输出: (高层臂 a_H, 低层臂 a_L)
```

### UCB公式的直觉解释

```
UCB值 = 平均奖励(越高越好) + 探索奖励(越少被选越高)
         ─────────────────   ─────────────────────

例如在第50轮(id=50), α=2.5:

  RBF: 被选了20次, 平均奖励0.6 → UCB = 0.6 + √(2.5×ln50/20) = 0.6 + 0.70 = 1.30
  GP:  被选了15次, 平均奖励0.7 → UCB = 0.7 + √(2.5×ln50/15) = 0.7 + 0.80 = 1.50 ← 选这个
  PRS: 被选了10次, 平均奖励0.4 → UCB = 0.4 + √(2.5×ln50/10) = 0.4 + 0.98 = 1.38
  KNN: 被选了 5次, 平均奖励0.3 → UCB = 0.3 + √(2.5×ln50/ 5) = 0.3 + 1.39 = 1.69 ← 虽然奖励低
                                                                                       但选的少,
                                                                                       探索项大!
```

## 三、8种组合臂的执行流程

### 3.1 总览: 模型-准则关联图

```
    高层臂(模型)              低层臂(填充准则)          产生候选解的方式
    ──────────              ────────────            ──────────────
                          ┌─ a₁: LCB ──────────→ DE生成N子代, 选LCB最小的
    a₁ᴴ: GP  ────────────┤
                          └─ a₂: EI ───────────→ DE生成N子代, 选EI最大的

                          ┌─ a₃: prescreening ─→ DE生成N子代, 选RBF预测最小的
    a₂ᴴ: RBF ────────────┤
                          └─ a₄: local search ─→ 在包围盒内用DE优化RBF模型

                          ┌─ a₅: prescreening ─→ DE生成N子代, 选PRS预测最小的
    a₃ᴴ: PRS ────────────┤
                          └─ a₆: local search ─→ 在包围盒内用DE优化PRS模型

                          ┌─ a₇: L1-exploit ──→ DE生成N子代, KNN预测L1级,
    a₄ᴴ: KNN ────────────┤                      选离已知好解最近的
                          └─ a₈: L1-explore ──→ DE生成N子代, KNN预测L1级,
                                                 选离已知好解最远的
```

### 3.2 每种组合臂的详细执行流程

#### {GP, LCB} 的执行流程 (GP_lcb_arm.m)

```
    当前种群 P (ghx, ghf)           DE算子                GP模型
    ┌──────────────┐      ┌──────────────────┐     ┌─────────────────┐
    │ x₁  f(x₁)   │      │ 对P中每个个体:     │     │ 用P训练GP模型    │
    │ x₂  f(x₂)   │─────→│  变异: v=x+F(xb-x)│     │ (公式2-6)       │
    │ ...          │      │       +F(xr1-xr2) │     │ 得到 μ(x), σ(x) │
    │ x₁₀₀ f(x₁₀₀)│      │  交叉: CR=0.9     │     └────────┬────────┘
    └──────────────┘      │  修复: 越界随机重置 │              │
                          └────────┬─────────┘              │
                                   │                         │
                                   ▼                         │
                          ┌──────────────────┐              │
                          │ N=100个子代        │              │
                          │ {o₁, o₂,...,o₁₀₀} │              │
                          └────────┬─────────┘              │
                                   │                         │
                                   ▼                         ▼
                          ┌──────────────────────────────────────┐
                          │  对每个子代 oᵢ, 用GP预测:               │
                          │    预测值 μ(oᵢ) 和 标准差 σ(oᵢ)        │
                          │                                        │
                          │  计算 LCB 值 (公式12):                  │
                          │    LCB(oᵢ) = μ(oᵢ) - w·σ(oᵢ)          │
                          │              ─────   ──────            │
                          │              利用     探索(w=2)         │
                          │                                        │
                          │  选 LCB 值最小的子代:                    │
                          │    x_t = argmin LCB(oᵢ)                │
                          └───────────────────┬────────────────────┘
                                              │
                                              ▼
                                    ┌──────────────────┐
                                    │ 检查 x_t 是否已   │
                                    │ 在数据库中?        │
                                    └────┬────────┬────┘
                                      是 │        │ 否
                                         ▼        ▼
                                  reward=0    真实评估 FUN(x_t)
                                              NFEs += 1
                                              加入数据库
                                              计算奖励(公式24)
```

#### {RBF, prescreening} 的执行流程 (RBF_pre_arm.m)

```
    当前种群 P ──→ 训练 RBF 模型 (公式7-8, my_rbfbuild.m, 立方基函数)
                        │
                        ▼
    DE生成N子代 ──→ RBF 预测每个子代的适应度 (my_rbfpredict.m)
                        │
                        ▼
                  选预测值最小的子代 x_t = argmin f̂_RBF(oᵢ) (公式17)
                        │
                        ▼
                  去重检查 → 真实评估 → 计算奖励
```

#### {RBF, local search} 的执行流程 (RBF_ls_arm.m)

```
    当前种群 P ──→ 训练 RBF 模型
                        │
                        ▼
                  确定搜索范围 (公式18):
                  lb_j = min(P的第j维), ub_j = max(P的第j维)
                        │
                        ▼
                  ┌──────────────────────────────────┐
                  │   在 [lb, ub] 内用 DE 优化 RBF 模型  │
                  │   (DE_optimizer.m)                   │
                  │                                      │
                  │   种群大小: N=100                     │
                  │   最大代数: 100×D + 1000              │
                  │   变异策略: DE/best/1                 │
                  │   停止条件: 连续10代改进 < 1e-20       │
                  │                                      │
                  │   注意: 这里的FE都是在RBF模型上的,     │
                  │   不消耗真实评估次数!                   │
                  └──────────────┬───────────────────┘
                                 │
                                 ▼
                  找到 RBF 模型上的最优解 x_t
                                 │
                                 ▼
                  去重检查 → 真实评估 → 计算奖励
```

#### {KNN, L1-exploitation} 的执行流程 (KNN_eoi_arm.m)

```
    当前种群 P (已排序) ──→ 分成5个等级 (公式11):
                              Level 1: 最好的20% (排名1~20)
                              Level 2: 次好的20% (排名21~40)
                              ...
                              Level 5: 最差的20% (排名81~100)
                                    │
                                    ▼
                              训练 KNN 分类器 (K=1)
                              训练数据: (解, 等级标签)
                                    │
                                    ▼
    DE生成N子代 ──→ KNN 预测每个子代的等级
                                    │
                                    ▼
                  筛选出预测为 Level 1 的子代集合 X¹
                                    │
                                    ▼
                  ┌──────────────────────────────────┐
                  │  L1-exploitation (公式19):         │
                  │                                    │
                  │  对X¹中每个候选 x:                   │
                  │    计算 x 到所有 Level 1 父代的距离   │
                  │    取最大距离 max_dist(x)            │
                  │                                    │
                  │  选 max_dist 最小的:                 │
                  │    x_t = argmin max_dist(x)         │
                  │                                    │
                  │  直觉: 选一个"被已知好解包围最紧"的,  │
                  │  即最深入已知好区域中心的点             │
                  └──────────────┬───────────────────┘
                                 │
                                 ▼
                  去重检查 → 真实评估 → 计算奖励
```

#### {KNN, L1-exploration} 的区别

```
    与 L1-exploitation 完全相同, 只是最后一步反过来:

    L1-exploitation: x_t = argmin_x max_p ||x - p||   (离好解最近 → 利用)
                                                         ↕ 反过来
    L1-exploration:  x_t = argmax_x min_p ||x - p||   (离好解最远 → 探索)

    代码差异:
      exploitation: max_dist = max(dist,[],2);  [~,in] = min(max_dist);
      exploration:  max_dist = min(dist,[],2);  [~,in] = max(max_dist);
```

## 四、TL-R 奖励更新流程

```
                    TL-R 奖励更新流程
                    (Algorithm 3, Low_level_r.m)

    输入: 当前种群P(ghf), 新解x_t的适应度(candidate_fit)
                          │
                          ▼
    ┌───────────────────────────────────────────────┐
    │  Step 1: 计算低层奖励 r_{a_L} (公式24)          │
    │                                                 │
    │  将x_t的适应度插入种群P, 排序, 找x_t的排名I(x_t)  │
    │                                                 │
    │  r = -1/N × I(x_t) + (N+1)/N                   │
    │                                                 │
    │  ┌─────────────────────────────────────────┐   │
    │  │ 排名I(x_t)    奖励r     含义             │   │
    │  ├─────────────────────────────────────────┤   │
    │  │  1 (最好)      1.00     比种群所有解都好  │   │
    │  │  20            0.81     排前20%          │   │
    │  │  50            0.51     中等             │   │
    │  │  80            0.21     排后20%          │   │
    │  │  101 (最差)    0.00     比种群所有解都差  │   │
    │  └─────────────────────────────────────────┘   │
    └────────────────────┬──────────────────────────┘
                         │
                         ▼
    ┌───────────────────────────────────────────────┐
    │  Step 2: 更新低层Q值 (公式25)                    │
    │                                                 │
    │  代码实现: Save_xx = [Save_xx, reward]           │
    │  低层Q值 = mean(Save_xx) (该低层臂所有历史奖励均值)│
    │                                                 │
    │  论文公式:                                       │
    │  Q_L(t+1) = [T_L(t)·Q_L(t) + r] / [T_L(t)+1]  │
    │           = 增量平均(等价于所有历史奖励的均值)      │
    └────────────────────┬──────────────────────────┘
                         │
                         ▼
    ┌───────────────────────────────────────────────┐
    │  Step 3: 更新高层Q值                             │
    │                                                 │
    │  代码实现: model_rewards = [model_rewards; reward]│
    │  高层Q值 = mean(model_rewards)                   │
    │         = 该模型所有关联低层臂的所有历史奖励的均值  │
    │                                                 │
    │  论文证明(公式30):                               │
    │  Q_H(t+1) = Σ Q_L(t+1) / |A_H^L|              │
    │           = 该模型关联的所有低层Q值的均值          │
    └───────────────────────────────────────────────┘
```

### 奖励传播示例

```
    假设第t轮: TL-UCB 选了 GP(高层) + LCB(低层)

    ┌─────────────────────────────────────────────────────┐
    │                    GP                                │
    │              Q_H = 0.65                              │
    │            ┌────┴────┐                               │
    │           LCB       EI                               │
    │        Q_L=0.55   Q_L=0.75                           │
    │        被选4次     被选3次                              │
    │            │                                         │
    │  新解x_t排名第21 (N=100)                              │
    │  低层奖励 r = -21/100 + 101/100 = 0.80               │
    │            │                                         │
    │            ▼                                         │
    │  更新 LCB 的 Q值:                                     │
    │  Q_LCB(t+1) = (4×0.55 + 0.80) / 5 = 0.60  (↑ 从0.55)│
    │            │                                         │
    │            ▼                                         │
    │  更新 GP 的 Q值:                                      │
    │  Q_GP(t+1) = (Q_LCB + Q_EI) / 2                     │
    │            = (0.60 + 0.75) / 2 = 0.675  (↑ 从0.65)   │
    │                                                      │
    │  结果: LCB表现好(奖励0.80 > 旧Q值0.55),               │
    │       LCB的Q值上升, GP的Q值也跟着上升                   │
    └─────────────────────────────────────────────────────┘
```

## 六、代码文件与流程的对应关系

```
RUN_AutoSAEA.m                    ← 实验入口, 多次运行取统计
    │
    └─→ AutoSAEA.m                ← 主算法 (Algorithm 1)
            │
            ├─→ lhsdesign()       ← 初始化: LHS采样
            │
            ├─→ DEoperator.m      ← DE算子: 生成N个子代 (公式14-16)
            │
            ├─→ TL_UCB.m          ← 计算UCB值 (公式22, 23)
            │
            ├─→ [8个arm函数]       ← 执行选中的组合臂:
            │   ├─→ GP_lcb_arm.m  ←   {GP, LCB}
            │   ├─→ GP_ei_arm.m   ←   {GP, EI}
            │   ├─→ RBF_pre_arm.m ←   {RBF, prescreening}
            │   ├─→ RBF_ls_arm.m  ←   {RBF, local search}
            │   ├─→ PRS_pre_arm.m ←   {PRS, prescreening}
            │   ├─→ PRS_ls_arm.m  ←   {PRS, local search}
            │   ├─→ KNN_eoi_arm.m ←   {KNN, L1-exploitation}
            │   └─→ KNN_eor_arm.m ←   {KNN, L1-exploration}
            │
            └─→ Low_level_r.m     ← 计算低层奖励 (公式24)

    模型训练/预测:
        GP:  GP_fit.m + predictor.m          (DACE工具箱)
        RBF: my_rbfbuild.m + my_rbfpredict.m (立方基函数)
        PRS: srgtsPRSSetOptions + srgtsPRSFit + srgtsPRSEvaluate
        KNN: ClassificationKNN.fit + predict  (MATLAB自带)

    局部搜索优化器:
        DE_optimizer.m   ← 在代理模型上运行DE (不消耗真实FE)
```
