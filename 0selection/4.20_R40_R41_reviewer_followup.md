## 1. R40A：NSS hierarchical encoder 从零训（对应 reviewer §4 的"正式 Plan B"）

### 配置
- Encoder：NSS-style（ICML25） HierarchicalCoordEncoder，d=128，block_num=2，encoder_layer_num=2，heads=8，downsample_ratio=0.8，ReZero residuals（α init 0）。
- 保留原有 `in_proj(d_in_max=8 → d)` 以兼容 18 问题不同 node 维度。
- ATSP 仍用 MatrixEncoder（reviewer §4 明确 MatNet 是 B3 后续子项）。
- Loss：Plackett-Luce listwise，pl_weight=1.0，pl_topk=6；其他 loss weight=0。
- 训练：50 epochs（上限）、batch_per_problem=8、aug_8fold、AMP、grad clip 1.0。
- 学习率：调了两版（见下），最终 peak lr=5e-5，warmup 2000 步，cosine decay 到 1e-5（cosine_total=600000 步）。
- Early-stop T1=0.45 @ ep10、T2=0.02 drop、T3=10 ep plateau<0.002、T4=12h wall-clock。

### 踩过的两个坑
- v1（peak lr 1e-4，cosine_total=40000）：cosine 在 step 40000 前就到底（实际每 epoch ≈ 30000 steps），相当于 1.5 个 epoch 后一直跑 min_lr=1e-5 → ep1 = 0.5148，后面 2 个 epoch 几乎不涨（plateau 在 0.515 附近）。
- v2（peak lr 1e-4，cosine_total=1500000，相当于整个训练都接近 peak lr）：ep1 = **0.5199**（已达 R18 0.5193！），ep2 = **0.4729**（从 0.5199 暴跌 0.047），T2 自动早停。TSP top1 从 0.721 掉到 0.220，CVRP 从 0.330 掉到 0.075。
- v3（peak lr 5e-5，cosine_total=600000，即本次正式版）：下面列出。

### v3 轨迹（最终版，lr 5e-5，50 epochs 上限带早停）

| Epoch | macro_top1 | TSP | CVRP | ATSP | 备注 |
|---:|---:|---:|---:|---:|---|
| 0 | 0.4653 | 0.197 | 0.339 | 0.703 | 初始 |
| 1 | **0.5189** | 0.725 | 0.364 | 0.703 | **best**，达到 R18 水准 |
| 2 | 0.5153 | 0.697 | 0.345 | 0.704 | −0.004 |
| 3 | 0.5048 | 0.647 | 0.338 | 0.703 | −0.014（TSP 开始掉） |

**46 分钟训练后 T2 divergence 自动停止（0.5189 → 0.4836，drop 0.0353 > 0.02 阈值）。**

### 核心观察

1. **NSS encoder 一个 epoch 就能达到 R18 水准（val 0.5189）**。说明新 encoder 在 18 问题混合下能快速学到东西。
2. **TSP top1 剧烈震荡**：0.197 → 0.725 → 0.697 → 0.647 → 0.211。这不是单纯过拟合，是**灾难性遗忘**：当 VRP 系 batch 占训练步数主体（15 个 MVRP × 1 TSP，TSP 每 18 步才遇到一次），TSP 特征被其他问题的梯度冲掉。
3. CVRP 和 ATSP 基本稳定（CVRP 在 0.33-0.36，ATSP 始终 0.703，ATSP 走的是 MatrixEncoder 路径，没改动）。TSP 是唯一出现灾难性遗忘的问题。
4. **ReZero 没有稳定训练**：v2 用 lr 1e-4 直接爆炸；v3 降到 5e-5 才能训 4 个 epoch。ReZero α 从 0 开始慢慢长，但当 α 变大后，高 lr 下突然开始主导残差，会放大遗忘效应。
5. 没有通过 gate（val ≥ 0.529）。

## 2. R40C：NSS encoder + LocalProblemHead 从零训（想用 per-problem 本地头防止遗忘）

### 配置
- 其他与 R40A v3 一样，**加 `--local-head`**：每个 problem 一个独立 `Linear(d=128) → GELU → Linear(K_p)` 的小 MLP，输出被 scatter 到 `(B, M_GLOBAL=18)` 上，与全局 head 做 `λ·global + (1−λ)·local` 的线性混合（λ = σ(logit)，初始 σ(0)=0.5，可学）。

## 3. R41：R18 base + LocalProblemHead fine-tune（"local head + R18 warm start"）

### 动机
既然从零训 NSS 打不过 R18（而且会灾难性遗忘），那就**保留 R18 的 encoder + 原 head，只加一个 LocalProblemHead 做微调**——相当于 Plan C 里 "二阶段精修" 的一种最简版本。

### 配置
- 载入 `runs/R18_alltail/best_top1.pt`（`missing=73, unexpected=0` → 73 个 missing key 全是 LocalProblemHead 新加的）。
- `--encoder-type standard --d 128 --depth 4 --use-film`（完全匹配 R18 结构）。
- `--local-head --freeze-except-local-head`：1,469,209 参数中，853,702 冻结（R18 backbone+head+solver_emb），615,507 可训（LocalProblemHead + local_head_logit）。
- Loss：Plackett-Luce，lr 3e-4（local head 从零起所以比 R18 原 lr 1e-5 大 30×），warmup 500，cosine 30000 → 3e-5，6 epochs。

## 5. 我对这三组实验给出的初步诊断（可能有错，reviewer 请帮我判断）

1. **在 18 问题混合 batch + 单 unified loss 下，encoder 从零训会灾难性遗忘 TSP**。这不是超参问题（lr 1e-4 和 5e-5 都一样结构性崩），也不是一个 epoch 够不够（ep1 才是 best，越训越差）。
2. **local head 可以延后但无法阻止遗忘**（R40C），说明 per-problem head 只能吸收"输出阶段"的差异，共享 encoder 的"中间表征"还是被 VRP 梯度压过 TSP 梯度。
3. **从 R18 热启动 + 只加 local head（R41）是目前唯一在 test 上产生正 Δ 的 train-time 方法**，但幅度只有 +0.0024，不显著，离 0.80 目标差 +0.28。
4. **Per-problem Δ 分布强烈证实 R39 gross decomposition**："救一份 VRPBL +0.022 就会伤一份 OVRPL −0.026"，问题本质没变。

## 6. 我想请 reviewer 重点判断的问题

请**具体、可执行**地回答（不要停留在"做个诊断 paper 也行"；用户的硬目标是把 top1 真实提升，不看创新性）：

1. **灾难性遗忘 vs 用户 80% 目标，哪个先解决？** R40 证明了从零训强 encoder 会崩。要想把 top1 提上来，**必须先解决 18 问题混合训练的稳定性**（比如 per-problem optimizer / gradient rescaling / stratified sampler / multi-task uncertainty weighting），还是**跳过 encoder，只做 Plan C 的二阶段 reranker**？

2. **R41 +0.0024 不显著，但方向是对的**。是不是值得按这个思路继续铺开：
   - 跑更多 seed / 更多 epoch（当前因 GPU 争用只跑到 ep3）
   - 加 curriculum（按问题相似度先训 TSP、再训 VRP 单 constraint、最后训多 constraint）
   - 每个问题用不同 lr（TSP lr ×5 之类）
   - Per-problem KL-divergence regularization（防止 fine-tune 偏离 R18 原始分布太远）

3. **如果要搞 Plan C reranker，应该怎么定义"二阶段"？**
   - 我之前的 R26b 系 rerank 尝试都失败了（val→test 不 transfer）。
   - 现有 reranker 都是在 R18 输出的 top-k 上做 pairwise 判别，但 R39 gross decomp 说 "zero-pick mass 17-20%" 是 upper bound——换句话说，只改 top-k 选择最多也就 ~0.02 提升天花板。
   - 是否应该改成 "hard example mining"（专挑 R18 预测错的样本训一个分类器）？还是"外挂专家 ensemble"（用 Specialists 0.5258 水准的模型做 fallback）？

4. **TSP 灾难性遗忘，有没有过去 paper 中已知解？** 我的 R40 observation 是：TSP top1 在 VRP 占主导的训练中会从 0.73 退化到 0.2。这属于典型 multi-task learning stability 问题。按你的经验，优先推荐哪一种 loss balancing / task scheduling 方法（GradNorm、PCGrad、MGDA、Uncertainty weighting、Round-robin batch、Stratified oversample…）？

5. **用户目标 80% top1 究竟合理吗？** 现在 SBS 上限 = 0.5368，VBS oracle = ~0.59，Specialists 最强 = 0.5258。在这个 label 结构下，top1 = 0.80 是否物理上不可能？如果做一个"理论天花板"分析（例如：基于 cost 分布的贝叶斯最优 top1），能给出个数字吗？
