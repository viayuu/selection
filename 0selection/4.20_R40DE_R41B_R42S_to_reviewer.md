## 0. 代码改动（已落盘）

- `code/unified_selector/train.py`：
  - 提取 `compute_loss_for_problem(model, batch, p, args, audit, teachers, base_model)` 作为模块级函数（原 L402-458 全部 loss 构建搬出），供三种 scheduler 复用。
  - 新增 `--task-schedule {block, round_robin, task_accum}`（默认 `block`，向后兼容 R18）。
  - `round_robin`：每步从 18 个 problem 各抽 1 个 mini-batch、随机打乱顺序、每个 mini-batch 立即 `opt.step()`，每 epoch 步数 ≈ min_loader × 18。
  - `task_accum`：累加 18 个 problem 的 `loss/18` 后做 1 个 `opt.step()`，每 epoch 步数 ≈ min_loader。
  - 新增 `--base-kl-weight/tau/ckpt`：基于 frozen base ckpt 做信任域 KL（复用 L454-458 distill KL 模板）；按样本 base 对错区分权重（correct=1.0，wrong=0.2）。
  - 新增 `--residual-adapter` flag（传给 model）。
  - 新增 `--grad-probe` / `--grad-probe-every`：每 N 步记录 encoder 共享层在 TSP 与 {CVRP, VRPBTW, OVRPBLTW} 的梯度 cosine，写入 `eval_epoch*.json["grad_cosine"]`。
  - `last_seen_step[p]` tracker 记录每 problem 最后被 update 的 step。

- `code/unified_selector/model.py`：
  - `LocalProblemHead.__init__` 加 `zero_init` 参数：当 `True` 时，最后一层 `Linear(hidden, K_p)` 的 weight 与 bias 全部 `zero_()`，保证初始 `delta=0`。
  - `UnifiedSelector.__init__` 加 `residual_adapter=True` 参数；当开启时 `local_head_logit` 初始化为 `logit(0.02)=−3.89`（σ=0.02，约 2% 残差权重）、forward blend 改为 `logits = base + σ(α[p]) · 0.2 · delta(h, p)`（cap 0.2 × delta，additive）。`residual_adapter=False` 时保留原 R41 凸组合模式 `σ(α[p]) · base + (1−σ(α[p])) · delta`。
  - `local_head_logit` 从 scalar `torch.zeros(1)` 改为 per-problem `torch.full((18,), init_val)`（reviewer §3.3）。

- `code/unified_selector/r41_test_eval.py`：修正 `zero_pick_mass` 定义。旧实现判定"某 arm 从未是任何 test instance 的 oracle"（所有 arm 都满足 → 0%）；改回 R29/R39 原始定义 `base_support[p] = set(base_picks[p])`，oracle_arm ∉ base_support 为 zp instance。

- `code/unified_selector/rerank_train.py`（新文件，约 500 行）：R42S 的 KEEP_SBS + full-pool reranker。输入：R18 per-arm logit + retrieval priors + arm behavioral stats + instance pooled h + problem_emb + cbits；输出空间 `{KEEP_SBS} ∪ {K_p arms}`；loss = CE + 0.5·pairwise_cost + 0.3·KL_to_base；per-problem threshold θ[p] 在 val 上扫 grid 最大化 macro top1，锁死不在 test 调。

## 4. R42S — KEEP_SBS + full-pool reranker

### 4.1 设计（reviewer §4）
- 输出空间：`{KEEP_SBS} ∪ {K_p arms}`（K_p+1 个 score）。
- 输入：R18 per-arm logit + retrieval priors (oracle vote + cost rank) + arm behavioral stats + instance pooled h + problem_emb + cbits。
- 两 MLP：`arm_scorer` (3-layer) + `keep_scorer` (instance-only)。
- Loss：CE + 0.5·pairwise_cost + 0.3·KL_to_base，sample_mix `0.4/0.25/0.25/0.10` (random/base-correct/base-wrong-oracle-in-pool/zp-or-high-regret)。
- 推理：val-locked `θ[p]` = argmax grid(−0.5..0.5, 21 steps) per problem。

### 4.2 结果
- Val macro_top1 = **0.5277**.
- **R42S test = 0.5162**，**SBS test = 0.5144**
- Δ = +0.0017 vs SBS，95% CI [−0.0043, +0.0077]，p(Δ>0) = **0.712**，非显著。
- Per-problem：TSP +0.026 / OVRPBTW +0.046 / VRPBL +0.021 / OVRPBLTW +0.022 大赢；VRPLTW −0.043 / VRPBLTW −0.028 大输（val→test threshold 反向漂移）。
- Val 0.5277 → test 0.5162，shrinkage 1.15%。**val 1k 样本定 per-problem θ 的噪声太大**。

## 5. 我想请 reviewer 给意见的三个具体问题

1. **R40D 首次过 95%（p=0.977），下一步该铺哪条路来再把 +0.0060 变更大**？我列出 5 个路径按 reviewer 判断排序：
   - (a) 多 seed 平均（现在只 seed=0，跑 3-5 个 seed 取 mean，期望 CI 收窄且 Δ 可能变大）；
   - (b) 把 R40D 的 encoder 当作新 base，再叠 R41B 的 residual adapter + base-KL（R40D + R41B 级联）；
   - (c) 把 R40D 的 encoder 和 R18 做 ensemble（logit mean 或 vote）；
   - (d) 延长 R40D 训练（更多 cold epochs + 更长 cosine 而不是 80k steps）；
   - (e) 改 R40D 的 encoder 容量（block_num=3, encoder_layer_num=3, d=256）看能不能把 CVRP 也拉上来（目前 CVRP 从 0.401 → 0.419 是增益，但仍有上调空间）。

2. **R40D 中 OVRPTW +0.055 是从哪儿来的**？R18 OVRPTW=0.444，R40D=0.499。这是单个 problem 最大增益。是 NSS 更好的 time-window feature encoding？还是 round_robin sampler 在 TW-constraint problem 上的 gradient 干扰更小？如果能定位到具体机制，可以强化（比如 TW-family problem 给更高 sampling weight）。

3. **R40D 的 harm_total = 1437 远大于 rescue_total = 264**，但 macro top1 仍然 +0.0060 显著。这似乎与 R39 gross decomp 的 "rescue ≈ harm so net is bounded" 诊断不一致。解读：R40D 不是靠 zero-pick rescue 拿增益，而是 **在 base support 集内部重排 arms**（per-arm distribution shifted, not new arms discovered）。如果 reviewer 同意这个解读，意味着 R40D 走的是 "改 ranking logit 幅度" 路线而非 "开 support 集" 路线；后续如果想同时利用 rescue，可以 R40D + retrieval prior blend（R25 retrieval 之前给了 127 zp rescues）。
