| 指标/分母 | R76 | R77B | B−R76 |

| 全18等权Top1 (%) | 69.439452 | 71.225218 | +1.785765 |
| 全18等权mean cost | 11.353131307 | 11.345771171 | -0.007360136 |

全18等权regret = (1/18)Σp mean_i(r_pi)。固定S的全18贡献 = (1/18)Σp Σ(i∈S_p)r_pi/N_p，**不是**在子集内重新求均值；conditional = Σ(p,i∈S_p)r_pi/14,077，按子集实例汇总，不把各题子集均值简单等权平均。CSV的每题/每方法all18_contribution也已含1/18，ALL18行是这些贡献求和。

固定S真实纠正对应全18Top1的毛贡献为 **+1.002710个百分点**，不能替代整体净Top1变化 +1.785765个百分点。全18regret净变化 -0.070129288pp = 固定S贡献变化 -0.031431529pp + 其余实例贡献变化 -0.038697758pp。原始成本跨题尺度不同，主成本结论使用上述逐行相对regret。
