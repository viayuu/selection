# R92D 完整模型：只读结果分析

主交付：[两页 PDF](ROUND_ANALYSIS.pdf)。仅再分析既有 full_model_statistics CSV/JSON；未加载权重或预测数组，未运行 GPU、训练、推理、重选、子代理或提交。

## 结论与证据强度

**D 不替代 R84A/R89B。** TEST Top1=69.571605%，actual regret=0.424277%；相对 R89B 分别为 -1.848148 pp、+0.034631 pp。VAL 同向落后，且不是仅少数方法的零选择问题。

正向证据也保留：D 在 TEST 相对 TRAIN SBS 的 Top1 提升 3.391358 pp；逐题等权 vs_SBS=-0.165902%。六个非常量任务的成本均低于 SBS，其余十二题完全等同 SBS。说明其成本选择仍有价值，但没有提高本项目完整选择器的已有水平。

## 方法、数据与冻结协议

普通 GPU CatBoost MultiRMSE，完整合法候选池 relative gap 监督；输入 357 维结构统计，无 NN embeddings，不把标签、winner 或成本作为前向输入。无类重平衡、神经损失。每题 3000 trees 全部训练完成；**最终评估统一使用 100 trees/task**，不能把训练完成的 3000 树预算误称为最终 3000 树推理结果。357 维、3000 树和普通 GPU CatBoost 配置来自本次任务交接；本轮只由统计目录核验锁定树数、指标及评估口径。

数据：`selection_data_new90k_B_filtered_single_reld_mt_seed2_20261018`；全部 18 题每题 TRAIN/VAL/TEST=81,000/4,500/4,500。旧 10,000 例不纳入本版本；留出集含已参与研发的成员，且同一 TEST 已用于研发，不称全新盲测。TSP/CVRP 候选按既有合法池；八个含 B 问题不含 RouteFinder/MoSES_RF/MoSES_CaDA，RELD_MTL 删除，RELD_MOEL 仅按原值命名 reld_mt，不合并两种 ReLD 的最低成本。

选择规则：只在完整 VAL 上，以逐题等权 macro_vs_sbs_pct 严格最小选择单一共同树数，首次平局优先；18 题使用同一锁定模型和推理规则，无逐题拼接、无 TEST/LIB 选型。SBS 在 FULL TRAIN 固定。全部 Top1/目标 winner 使用 native/FP64 原始 int64 ind，非 FP32 argmin。

D checkpoint SHA256：`d2ffe0cdf8f4a33c7dc6817b4d04f10a9129dc6644011d4bd98d3e4b8c2523a3`。R84A/R89B 均为同数据、同候选池历史参考，没有重训，不是等算力或新鲜 matched control。

## 这次 family test 支持什么，不支持什么

**直接支持，单次冻结运行的描述性证据：** 独立于神经 embeddings/maximin/R-Drop 的结构统计 + 全池成本回归路线在本数据/候选池/锁定规则下未胜出，且同时呈现常量选择与目标不恢复。类似现象可在没有神经损失链路的方案中发生；神经 maximin/R-Drop 不是产生该现象的必要条件，但这不排除它们影响神经模型。

**不能推出：** 所有树模型或结构统计都不行、任何模型已到上限、Bayes ceiling、标签/数据噪声已被证实，或某个具体部件是唯一根因。输入表征、MultiRMSE 目标、树配置和统一 VAL 截断共同变化，不能分别归因。历史参考非等算力，单 seed、无多种子置信区间；LIB 仅 49/100 例且与合成分布不同，TEST 亦已研发暴露。不能把本次负向 family test 外推成不可约误差证明。

**处置建议：** 保留 D 为已完成的异构监督路线证据，不替换当前神经参考。本报告不提出新 GPU 预算、追加小变体或重新选型。C 的 cache/live VAL 问题不在本轮范围。
