# R114 Paired Response Diagnosis

Complete full-pool pairs: **1536/1536**. These are descriptive paired-response measurements, not selection improvements.

Only fixed TRAIN bases were used. Base and intervention costs were freshly solved under the same locked deployment. A missing candidate masks the full-pool winner; partial candidate deltas never manufacture a winner.

The main comparison is directed minus random on the SAME problem/family/base intersection. All candidate differences are in native cost units before descriptive scaling by the original endpoint oracle. A common shift to all methods yields zero relative response. Related endpoints/pairs are not counted as independent instances; no significance or causal-internals claim is made.

No model was trained here. Natural full18 TEST/LIB performance is not inferred from intervention winner flips. The frozen original dataset and its labels are unchanged.
