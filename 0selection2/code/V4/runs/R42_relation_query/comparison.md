## 解释边界

这是单个 seed 的架构/训练对照，不证明多 seed 稳健性。A 与 B 的比较同时改变编码器和读出路径，不能把差异独立归因于 Q/K/V。
与 R39A 的比较同时改变 batch、训练调度、早停和 R-Drop，不能单独归因于一致性正则。
没有重新生成 solver 标签，也不把 R41 的两个 RELD 方法的稳定性推广到全部候选池。
