# R107: 显式连接片段与资源组合

2026-10-24。根据第二轮Astra调研，由gpt-6.1-sol/max进行实施、检查和运行。

## 唯一研究问题

在同一套原始输入、完整18任务和合法候选池下，显式保留有向短片段的共同中间节点、几何连接和已知资源组合，是否比边因素分开处理更能学习实例级方法优势？这不是预测solver路线，不增加标签，不改变任务定义。

## 两组

- `A_edge_factorized`：新增模块以边因素分开计算的方式提供内容。
- `B_connected_paths`：同一模块对真实连接的短片段及资源组合进行联合计算。

两组使用相同完整新参数初值、固定的R84从头随机初值和TRAIN-only几何统计。主干仍为4层128维节点Encoder、2层原双流、方法ID+34维特征、原共享评分头和maximin。新片段通路在编码过程中更新，不是原Encoder结束后的边辅助头。总参数匹配不冒充相同有效函数自由度或FLOPs；具体边界由MODEL_PREP记录。

## 固定训练与评估

- 冻结NEW90k：每题81,000 TRAIN、4,500 VAL、4,500 TEST，沿用单一reld_mt及B题删三方法规则。
- seed=2，逻辑batch=1024；57,600次成功更新，warmup4,320；每1,440次完整VAL；每7,200次TRAIN诊断。
- 原AdamW、峰值LR1e-4、末LR1e-6、WD1e-4、dropout0.1、逻辑梯度clip1；原CE/comparison/risk/R-Drop，不另加辅助loss。
- 正式共同microcap为TSP/CVRP256、其它1024、eval128；开跑前最大TRAIN规模双Dropout反传见证已通过，最重CVRP峰值allocated18,856MiB，TSP峰值reserved21,618MiB。逻辑batch仍为1024，不在训练中自动缩小或改预算。
- 唯一checkpoint按完整18题VAL的`macro_vs_sbs_pct`严格最小选定；TRAIN拟合SBS。随后同一checkpoint完整TEST、LIB、独立模型耗时和PDF。
- 复用已有R84输入缓存；路径/资源量仅由当前允许输入构造，不读取当前cost/winner、真实路线或solver输出。
- 不恢复R58、不添加经典B顺序规则、不补求解标签。当前部署未核实的语义不添加硬可行性mask。

## 结论边界

固定R84零/近零36组仅占约五分之一错误，不能只报告其选择次数。交付包括全18题Top1、mean_cost、actual regret、SBS/Oracle，逐方法真winner召回、误选及净成本。六节点ATSP结构反例不是实际平台原因证明；TRAIN-only小样本机制桥接也不是泛化收益。旧TEST已参与研发，不宣称盲测。

前置的轻量TRAIN-only分析是阴性：五题各1,024例上的平均片段统计加线性ridge，相对边统计均未改善留出TRAIN的成本gap误差。结果完整保留在`preparation/ADVANTAGE_BRIDGE.md`，不以个别正相关挑出“通过”的证据。R107因此不是已认证有效结构的扩展，而是一对可证伪的全任务计算机制实验：比较保留可学习节点/片段对应和联合资源计算，与分离边因素计算的差别。它不同于将片段平均成几个静态统计；这项差别仍不足以保证收益。此轮用户已明确授权继续实验，由Sol作执行决定，不声称Astra已确认它会改善选择。

推进仅依据完整锁定模型对匹配对照及历史参照的联合收益；边特征变化、训练拟合或零选择组数减少不能代替选择效果。不因微小波动自动追加参数搜索。
