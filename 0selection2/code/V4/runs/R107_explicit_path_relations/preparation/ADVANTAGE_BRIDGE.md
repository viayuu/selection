# 显式路径组合与方法相对优势：有界 TRAIN 检查

## 结论：这组摘要的增量假设未获支持

**五题的总体 `delta_R2` 全部为负。** 在固定的条件及边际统计之外，追加本次少量、平均化的确定性短路径/资源摘要，没有降低 TRAIN 内留出样本的方法相对成本回归误差。保留这一阴性结果，不追加特征、阈值、正则强度或划分搜索，不查看 validation/TEST，不把零散单方法正值挑出来宣称总体桥梁成立。

这是对**这些摘要在这一次小样本、固定线性探针下具有增量预测作用**的有用局部反证，不是一个需要调到绿色的失败预检查。它没有检验可学习的高阶路径状态、未汇总的片段对应关系、候选条件化片段读出或端到端神经模型，因此也没有否定所有显式路径模型。不能据此承诺、估计或认证下一轮 selector 的收益；任何后续完整实验都须独立承担其证据要求。

## 固定设计与效应

- 每题 1,024 条冻结 TRAIN，共 5,120 条；每题独立分析，不混合不同问题的 raw cost。选择输入条件相同的 16 个单元，每单元 64 条，32 条拟合、32 条留出。因此每题拟合 512、留出 512；这里的留出仍是 TRAIN 子集，绝不是项目 validation 或 TEST。
- 单元键为缓存真实节点数 `n`、生成 `distribution` 和 `capacity_type`；从至少有 64 条的单元按排序后的等距位置固定选取 16 个。单元内随机无放回抽样，种子依任务顺序为 `10702` 至 `10706`。CVRP/VRPL/OVRPL 的 `n` 包含 depot。样本行号、基础 source index、全部条件单元均保存在 JSON。
- 三个比较对象为：拟合半份的条件均值；条件均值加边际摘要 ridge；再追加组合摘要的 ridge。各输入先减去拟合半份的对应条件均值，再按拟合半份的标准差缩放。固定 `alpha=10`，无搜索、无重复选型、无神经或树模型。元数据只用于抽样/条件控制，不作为特征函数输入。
- 所有合法方法同时作为响应，`y_m = 100 * (FP64_cost_m / mean_legal_pool_cost - 1)`。这是每例以合法池平均成本归一的相对成本，不是 Oracle regret、winner 分类或 selector 推理。方法间的响应之差就是同分母的方法成本差。
- MSE 先逐留出实例、再逐合法方法等权平均。定义 `R2 = 1 - MSE_model / MSE_condition`，`delta_R2 = (MSE_edge - MSE_composition) / MSE_condition`。正值才表示追加组合摘要降低误差；负值表示变差。响应以百分数表示，MSE 的单位为其平方。

| 问题 | 条件 MSE | 加边际 MSE | 再加组合 MSE | 边际 R2 | 组合 R2 | delta_R2 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| TSP | 3.820037 | 3.077509 | 3.086731 | 0.194377 | 0.191963 | **-0.002414** |
| CVRP | 14.007264 | 11.245419 | 11.249328 | 0.197172 | 0.196893 | **-0.000279** |
| VRPL | 84.200024 | 73.186112 | 73.478773 | 0.130807 | 0.127331 | **-0.003476** |
| OVRPL | 138.976826 | 117.514419 | 120.754205 | 0.154432 | 0.131120 | **-0.023312** |
| ATSP | 19.535496 | 19.026924 | 19.154456 | 0.026033 | 0.019505 | **-0.006528** |

边际摘要相对条件均值在五题均降低误差，但这不是组合摘要的收益。OVRPL 的追加误差尤其明显。没有置信区间、重复划分或显著性认证，不能把很小的差异当作稳定总体效应；同样不能因其接近零而把负值改写为正向证据。完整逐方法误差保存在 JSON，仅作透明记录，不从中事后挑选总体结论。

## 实际计算了什么

距离使用缓存输入：坐标题由 FP32 坐标转 FP64 后计算欧氏距离；ATSP 保留缓存有向矩阵，不对称化。此处 FP64 方法成本与 FP32 原始模型输入是不同对象，没有使用成本构造距离。路由题的邻域只含客户，depot 关联另行计算。

**边际摘要：**非对角边长均值、边长标准差/均值、最近邻距离均值/全局边长均值、最近邻距离标准差/全局边长均值。最后一项在脚本中名为 `nn_cv`，其分母实际是全局边长均值，不是最近邻均值。路由题再加缓存需求的均值/标准差及 depot 到客户距离的均值/标准差，共 8 项；TSP/ATSP 共 4 项。

**组合摘要：**固定每点 3 个最近出邻居，枚举 `j in N3(i), k in N3(j)` 且三点互异的连接片段，不搜索路线。公共三项为 `(d_ij+d_jk-d_ik)/mean_edge` 的平均、`i in N3(k)` 的三步闭合比例、同一片段两条边长的相关系数。这里的闭合比例是采样邻域的局部统计，不是完整图 `trace(A^3)`。

路由题增加三客户缓存需求和大于 1 的片段比例；VRPL/OVRPL 再增加 `depot->i->j->k` 短片段 travel/L 的平均和超过 L 的比例。VRPL 代理额外计 `k->depot`，OVRPL 代理不计返库。**这些是输入可计算的局部数值代理，不是各候选原生环境已逐一认证的可行性判定，更不是完整路线或容量/长度可行证明。** 示例中的需求阈值与 L 超限比例均为零，不能据此声称覆盖了活跃瓶颈；也没有为了触发约束而追加长度或阈值搜索。

本次没有 TW 题、B 题、signed-load 阶段规则或时间窗算术；没有增加未经核实的 B 契约。低阶片段的平均化可能本身抹掉对应关系/极端事件，局部阈值也可能不活跃。这些是该阴性证据的边界，不是将结果豁免为成功的理由。

## 真实例证：关系不同，不等于关系解释了优势

每题只在留出 TRAIN、同一个条件单元内，选**边际摘要标准化 RMS 距离最小**的一对实例；配对仅用输入，随后才展示成本与 winner。不是按 winner 翻转、方法收益或组合差异最大挑例。它们的边际摘要接近但不完全相等，更不是原始输入碰撞证明。

下表两组数始终按 source A、B 顺序。方法差 `gap(A_method,B_method)` 指 `100*(cost_A_method-cost_B_method)/mean_legal_pool_cost`；正值表示前一方法更贵，不是相对 Oracle 的 regret。

| 问题与相同条件 | source A / B | 边际 RMS | 闭合比例 A / B | 展示的方法差 A / B |
| --- | --- | ---: | --- | --- |
| TSP，n=229，Gaussian，none | 45620 / 45695 | 0.02029 | 0.43023 / 0.41981 | LEHD-DIFUSCO：-0.3295 / -1.7636 |
| CVRP，n=291，Gaussian，scale | 57986 / 57957 | 0.10319 | 0.43588 / 0.42746 | RouteFinder-LEHD：+1.0418 / +3.6026 |
| VRPL，n=91，ring，mvrp_default | 81609 / 81688 | 0.14379 | 0.36765 / 0.40997 | reld_mt-MoSES_RF：+0.1057 / -0.4402 |
| OVRPL，n=101，uniform，mvrp_default | 99682 / 99694 | 0.14287 | 0.39474 / 0.41642 | reld_mt-MoSES_RF：+4.8560 / +1.3578 |
| ATSP，n=62，matrix_closure，none | 57474 / 57555 | 0.08535 | 0.07692 / 0.01630 | MATNET-UNICO_MatPOENet：+9.1341 / +27.0540 |

例如 VRPL 两例的局部关系不同，展示的方法差发生符号变化，native winner 分别为 MoSES_CaDA、reld_mt；但 CVRP 两例的 winner 都是 ICAM，ATSP 两例也都是 ICAM_ATSP。所有例子的完整 FP64 成本、所有方法响应、全部摘要及一条固定首片段的节点/距离/资源数值都在 JSON，不隐藏未翻转的实例，也不把展示的二方法差替代完整池。

这些例子只证明真实数据里“同已控制条件、边际接近、组合不同且方法差也不同”的现象存在。其余几何、需求、排列及部署因素仍可能不同；没有干预、没有充分条件控制、没有机制归因。**它们不建立因果联系，不证明原编码器合并了这些实例，也不能推翻五题增量回归均为负的主要结果。**
