# Finite Full18 Collection Protocol

The immutable structural source and planned_v1 input/recipe/seed contracts are
unchanged. Main owns R120 completion/release and every GPU/transport allocation.
CPU materialization alone is authorized now; no solver or GPU is run here.

Decisions before implementation:

- A wave is finite, with a REQUIRED positive max-jobs budget. Deployment groups
  are assigned by stable sorted deployment index modulo the fixed lane count.
  One deployment stays on one main-owned physical binding for this collection.
- One saved real original-endpoint preflight per deployment/binding precedes
  production labels. All18/89 remain in the manifest, including failures.
  A recipe's existence is not runtime qualification. Failed/unavailable methods
  never become illegal, zero-cost, or silently skipped in a complete export.
- Default `cold_native` keeps the frozen plan's fresh backend per task. Optional
  `cached_native_v1` is an EXPLICIT NEW execution-layer version/root: one backend
  per deployment child process, native singleton calls and per-input RNG reset,
  R114 lazy-runner resets, unchanged full solver budgets/checkpoints/profile.
  It is not called historical replay or proved fresh/warm equivalence. Do not
  mix modes in a collection root. Parent chooses whether to authorize that mode.
- Each deployment child gets its own Python module namespace, so the corrected
  CVRP cold scripts cannot be shadowed by another task's original factory import.
  TSP/ATSP use actual native tensor adapters and independent route audits.
- Main's R120 final TEST/LIB/report release receipt and physical host/UUID/CPU
  binding are mandatory BEFORE any backend load. CUDA availability is never a
  release signal. No polling, auto-retry, SSH allocation or GPU probing exists.
- Solver receipts retain immutable plan/input/deployment/seed/binding identities,
  native cost and tour, audit, elapsed load/solve time, collection mode/version
  and source hashes. Only successful LABEL receipts enter the saved-only export;
  preflight results are never promoted to labels.
- Complete export requires all113920 frozen full-pool tasks. Labels stay in a
  new collection namespace and never replace old90k costs/winners. The export
  includes original endpoints, all factor cells and TRAIN-only base partitions.

Natural TRAIN CE plus the new structurally generated full-pool population is a
different exposure distribution from historical models. R121 learner protocol
will declare that explicitly; no collection throughput or learning benefit is
inferred from CPU generation.
