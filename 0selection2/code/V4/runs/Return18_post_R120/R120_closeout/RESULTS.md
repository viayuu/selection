新6题中 MIS、FJSP、SMTWTP 的平均原生目标优于 TRAIN 拟合 SBS；JSSP、BPP、MKP 与 SBS 持平，不能把高 Top1 都归为选择收益。

actual regret 是逐实例有向损失/正 Oracle 的均值；vs_Oracle、vs_SBS 是同题均值比。两者不可替代；SMTWTP 的均值比仅 0.1197%，不是 15.509% 的逐实例 regret。

严格零选定义为整个 TEST 的选择次数恰为0，不是“少选”。正唯一支持是真实遗漏机会；仅并列支持可能由其它最优解覆盖；空最优组不能算漏选。

表中各组模型选择均为0；Routing 每题4500例。原18题的32个零选组中，26个具有正 native winner 支持，其余6个无最优支持。原生 winner 与含并列支持分别统计；新6题没有独立 native ind，不能用 canonical 首项冒充原生 winner。

空最优组：FJSP/SPT、OVRPBLTW/MTPOMO、OVRPBTW/MTPOMO、OVRPLTW/MTPOMO、OVRPTW/MTPOMO、VRPLTW/MTPOMO、VRPTW/MTPOMO。

BPP/BFD 与 FFD 均无唯一最优，但各有126例并列支持；模型各漏掉9例正损失，事件可能重叠，不得把两组损失直接相加。

全部方法的完整 TEST native/唯一/并列支持、选择数及损失见 method_support_test.csv；空组和零 native 但有并列支持的组分别保留。

## 结论

结论：新任务已形成可比较结果，但部分任务仅复现 SBS；Routing 未超过 R94B，且 TSP LEHD/DIFUSCO 等正支持组仍零选。后续方向应围绕实际遗漏与成本收益，不靠并列或空组制造改进。
