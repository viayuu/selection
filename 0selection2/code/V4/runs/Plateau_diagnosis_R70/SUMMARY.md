# 分析

除特别注明外，以下都是 test 结果；18任务按问题等权平均。regret 表示所选方法比该实例最便宜的方法平均贵多少，越低越好。

各表只保留一个模型示例，统一写“模型”；不同表可能使用不同已有权重，不合并视为同一个模型的成绩。具体来源保留在[详细报告](report.html)。

## 模型是否学到了选择信息

| 使用的信息 | Top1 |
| --- | ---: |
| 只看问题、规模，选训练中当前规模最常获胜的方法 | 42.20% |
| 用统计特征分组，选组内最常获胜的方法 | 46.19% |
| 模型 | 48.24% |

特征分组：客户数量、坐标中心、到中心的距离、客户间距离、depot位置、需求、时间窗、服务时间、ATSP矩阵边成本。每个问题单独用一棵深度3的树分组，规则只从train学习。

**结论：模型学到了选择信息，但简单统计已经能解释相当一部分成绩。**

### 不同方法是否擅长不同区域

CVRP比较 OMNI 与 RELD_CVRP：正值表示OMNI更便宜。ATSP比较 UNICO_MatPOENet 与 ICAM_ATSP：正值表示UNICO更便宜。

优势为每例两方法成本差除以该例Oracle后再平均，单位pp；不是获胜率。低/高需求以容量归一化平均需求0.0468134为界，边界只由train确定。

| 区域 | Train/Val/Test样本数 | Train优势 pp | Val优势 pp | Test优势 pp |
| --- | ---: | ---: | ---: | ---: |
| CVRP：162至277客户，低需求 | 935 / 90 / 107 | -3.752 | -3.781 | -3.924 |
| CVRP：162至277客户，高需求 | 1584 / 170 / 167 | +0.482 | +0.591 | +0.506 |
| CVRP：278至389客户，低需求 | 1179 / 119 / 117 | -3.324 | -3.376 | -4.032 |
| CVRP：278至389客户，高需求 | 1303 / 120 / 124 | +0.637 | +0.761 | +0.777 |
| ATSP：20至40节点 | 2604 / 273 / 273 | +11.387 | +11.959 | +10.860 |
| ATSP：41至60节点 | 2476 / 247 / 247 | +5.511 | +5.503 | +5.650 |
| ATSP：61至80节点 | 2460 / 240 / 240 | -1.694 | -1.963 | -1.957 |
| ATSP：81至100节点 | 2460 / 240 / 240 | -6.980 | -7.112 | -7.147 |

**结论：确实存在跨train/val/test一致的方法偏好。** CVRP低需求更偏RELD_CVRP，高需求更偏OMNI；ATSP小规模更偏UNICO，大规模两者比较时更偏ICAM。区域平均更好，不代表每个实例都赢，也不代表ICAM在大规模一定胜过其他全部方法。

## 是不是只记住了选方法的比例

把同问题、同规模实例的预测互相交换100次：保持总体选方法比例不变，只破坏“这个实例对应这个预测”。下面是交换后的平均结果。

| 模型 / 范围 | 原Top1 | 交换后Top1 | 原regret | 交换后regret |
| --- | ---: | ---: | ---: | ---: |
| 模型 / 全18任务 | 47.91% | 39.43% | 0.9432% | 2.1168% |
| 模型 / CVRP | 48.10% | 25.67% | 0.6138% | 1.9592% |
| 模型 / VRPTW | 43.50% | 25.40% | 1.4119% | 5.4560% |
| 模型 / ATSP | 77.50% | 76.05% | 0.3274% | 0.4055% |
| 模型 / OVRPTW | 49.10% | 45.59% | 0.8190% | 1.0197% |
| NSS / TSP | 35.10% | 29.45% | 0.6088% | 1.0718% |
| NSS / CVRP | 45.90% | 26.32% | 0.5695% | 1.8111% |

**结论：不是只学了选择比例，模型与NSS都利用了实例信息。** CVRP、VRPTW的实例级增益明显；ATSP更多依赖规模，OVRPTW的额外实例级增益较弱。没有第二个同规模实例时保留原预测，不放宽条件；全18任务可交换覆盖率98.88%。

## 剩余错误主要卡在哪里

按模型给各方法的排名，统计真正winner的位置。

| 错误类型 | 错误数 | 占全部错误 | 占总regret |
| --- | ---: | ---: | ---: |
| winner排第二，只是没有排第一 | 6,147 | 64.09% | 64.36% |
| winner排第三 | 1,951 | 20.34% | 20.31% |
| winner不在前三 | 1,493 | 15.57% | 15.32% |

**结论：主要卡在头部候选之间的最终排序，不是完全找不到好方法。** MOEL/MTL互选贡献48.52%的regret，但其余方法比较仍占51.48%，不能只研究这一对。

高Top3也不一定全是模型能力：OVRPTW固定三个强方法就覆盖99.9%的winner，与模型相同；CVRP固定三个只覆盖64.5%，模型为81.1%，后者才有明显动态候选增益。Top3覆盖不是只执行一个方法的准确率。

### 有些方法是不是一直被忽略

使用同一模型权重统计train和test；“获胜占比”与“被选择占比”不是同一个指标。

| 问题 / 方法 | Train获胜占比 | Train选择占比 | Test获胜占比 | Test选择占比 |
| --- | ---: | ---: | ---: | ---: |
| TSP / BQ | 30.77% | 64.21% | 28.00% | 65.00% |
| TSP / LEHD | 16.23% | 0.34% | 18.50% | 0.50% |
| TSP / T2T | 10.90% | 0.74% | 11.40% | 0.50% |
| VRPTW / MVMOE | 6.29% | 0.00% | 6.60% | 0.00% |

**结论：部分方法在训练集就很少被选，不能全部解释为测试时泛化失败。** 但不能直接强制选够次数，还要看选它失败时的代价及能否识别它的获胜条件。

## 是不是因为方法成本太接近，才很难选对

按每例真正第一、第二名的相对成本差分组，统计模型选错造成的损失。

| 真正前两名成本差 | 实例数 | 错误数 | 占总regret |
| --- | ---: | ---: | ---: |
| 完全相等 | 38 | 29 | 0.01% |
| 大于0、不超过0.1% | 1,390 | 919 | 2.91% |
| 0.1%至0.5% | 4,244 | 2,660 | 11.73% |
| 0.5%至1% | 3,458 | 1,951 | 13.04% |
| 1%至2% | 3,774 | 1,980 | 21.41% |
| 大于2% | 5,096 | 2,052 | 50.90% |

**结论：不能全部归因于近似并列，差距超过2%的实例贡献了一半剩余成本损失。** TSP更接近：69.9%的实例前两名差距不超过0.5%；但不能把TSP推广到全部任务。

## 为什么改了很多轮，总分仍差不多

对比模型一次改动前后的预测，共18,000个test实例。

| 变化 | 实例数 |
| --- | ---: |
| 改变了选择 | 4,670 |
| 纠正原有错误 | 1,682 |
| 把原本正确的改错 | 1,897 |
| 两者都错，但变便宜 | 473 |
| 两者都错，但变贵 | 617 |
| 两者都错，改选但成本相等 | 1 |

**结论：不是改动没有影响，而是纠正与新增错误互相抵消。** 另外，15个历史模型共同选错5,146例，占28.59%，贡献表中改动后模型49.17%的regret；这些共同错误值得定位，但不能据此宣布它们不可学。

## NSS也有类似问题吗

使用相同本地数据与候选池，统一按原始标签重算。普通test与LIB各保留一个已有模型示例，两部分不是同一权重。

| 数据集 | NSS Top1 / Top3 | 模型 Top1 / Top3 | NSS regret | 模型 regret |
| --- | ---: | ---: | ---: | ---: |
| TSP test | 35.10% / 72.20% | 35.90% / 75.20% | 0.6088% | 0.6504% |
| CVRP test | 45.90% / 77.70% | 48.10% / 82.20% | 0.5695% | 0.6138% |
| TSPLIB，49例 | 38.78% / 81.63% | 55.10% / 83.67% | 0.4353% | 0.3431% |
| CVRPLIB，100例 | 68.00% / 87.00% | 69.00% / 88.00% | 0.2724% | 0.3429% |

**结论：本地NSS也有低Top1，但不是所有指标都比模型差。** TSP/CVRP test上，模型的Top1更高，NSS的成本损失反而更低。NSS训练抽样准确率与val/test接近，也不能统一归为严重过拟合。

原论文排序损失的Top1为TSP约35%、CVRP约62%、TSPLIB约40%、CVRPLIB约56%，没有可直接比较的Top3命中率表。候选池不同，不能直接要求本地复现达到原数字；本地还存在validation选型指标差异，不是严格重做原论文。数字来源见[详细报告](report.html)。

## 提高Top1和降低成本，是不是同一件事

在完全相同的训练规模分组内，只把决策从“谁最常赢”改成“谁平均相对成本最低”。

| 问题 | Test Top1变化 | Test regret变化 |
| --- | ---: | ---: |
| TSP | -7.30个百分点 | -0.5072个百分点 |
| CVRP | -2.80个百分点 | -0.7108个百分点 |
| VRPTW | +3.20个百分点 | -0.3296个百分点 |

**结论：有些问题存在准确率与成本取舍，有些可以同时改善。** 不能只盯Top1，也不能据此断言换一个loss就能突破。

## 是不是train与test差太多

“非规模越界”指至少一项所测几何、需求等特征超出train范围。

| 数据集 | 规模范围 | 规模超出train的比例 | 非规模越界比例 |
| --- | --- | ---: | ---: |
| TSP test | 50至499 | 0.00% | 0.50% |
| TSPLIB | 51至1002 | 14.29% | 87.76% |
| CVRP test | 50至499 | 0.00% | 0.20% |
| CVRPLIB | 100至1000 | 32.00% | 52.00% |

**结论：普通val/test的规模与所测粗统计接近train，暂不支持明显的粗分布偏移；LIB明显更不同，必须单独评价。** 这不证明普通test覆盖充分，也不能指定是哪项变化造成LIB性能下降；越界比例不是不可预测比例。

## 不换网络，现有分数还能改善多少

只用train建立查表规则：在相似规模、相同有序Top2和相近分数差下，选平均相对成本更低的那个方法。只重排原Top2，不新训神经模型。

| 使用方式 | Val Top1 | Test Top1 | Val regret | Test regret |
| --- | ---: | ---: | ---: | ---: |
| 模型 | 48.38% | 46.72% | 0.9888% | 1.0052% |
| 分数条件查表，按平均相对成本选择 | 48.54% | 47.37% | 0.9821% | 0.9859% |
| 再增加一个几何／约束描述符 | 48.34% | 47.13% | 0.9771% | 0.9937% |

**结论：能恢复少量退化，但不是突破；增加这个描述符也没有稳定收益。** 这是回顾性诊断，不是正式发布的新模型结果。

## 总结

- 模型确实学到了实例信息，数据也确实存在可迁移的方法偏好。
- 平台的直接表现是：头部排序仍弱、部分方法长期被忽略、改动带来的纠正与伤害抵消；尚未确认一个共同根因。
- 不能据此说方向没有价值，也不能说已经达到上限；下一步需要针对明确的获胜条件与实际成本错误，而不是只期待更复杂的网络自然提高Top1。

备注：本轮没有重训、复跑solver或修改标签。带B任务已知的旧约束语义问题仍待处理；以上均为旧场景统计。几何距离统计在超过128客户时使用固定子集。
