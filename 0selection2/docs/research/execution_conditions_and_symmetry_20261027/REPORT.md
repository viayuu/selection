# 执行条件与对称性：学习对象需要澄清，主方向仍未就绪

2026-10-27 · 有界原始论文科学报告 · 决定：**NO_READY_MAIN_DIRECTION**

当前会话的 `turn_context` 实际记录为 `gpt-6-astra`、`max`，与请求一致；这项配置核对不等于独立认证 provider 的生成路由。本文直接阅读三篇原论文的指定部分；项目事实接受 Sol 的 [REQUEST.md](REQUEST.md)，未查源码或重新认证数值。下文将论文结论、所供事实与本文推导分别说明。

**没有足够依据将“实例＋候选执行条件”晋升为新的 whole18 主线。** 它是必要的目标定义，但未证明是当前主要缺口。TSP 的物理 node0 已进入 R94B；CVRP 的起点由原生 decoder TopK 内生决定；只有新捕获的 MATNET 随机角色提供了明确的随机初始条件实例，其历史标签对应实现仍未知。唯一保留的是旧原生过程储备的一项条件化收紧，不建议据此启动新模型。

**二、应该预测固定方法，还是固定方法的一次实现？**

令 X 为完整合法实例及已知物理标记，M(X) 为该题冻结合法候选池。对候选 m，固定部署配方 D_m 包含权重、adapter、归一化、解码、增广与归并规则、有限执行范围和原标签的计费口径。需要区分时，将一次成本写为：

$$
C_m=F_m(X,Z_m;D_m),\qquad Z_m=(R_m,U_m,H_m).
$$

R_m 是实际角色赋值，U_m 是外生随机输入，H_m 是其余相关执行状态。只有这些量确实足够时，F_m 才表示确定函数；写出符号并不证明状态已知、廉价或可恢复。固定 D_m 的常量通常可由候选身份确定，不因重复输入它们而新增实例证据。

| 条件类别 | 科学含义与知识边界 |
| --- | --- |
| 已知物理 start/end/start-set | 是带节点对应的角色。若由 X 与配方唯一决定，则属于可计算函数，不是额外随机变量；当前 TSP 锚点已被表示。 |
| 外生随机初始化 | 如实际 MATNET col 角色。应区分赋值 R_m 与生成它的 seed；角色可能影响执行，seed 的数值邻近一般不意味着行为邻近。 |
| 内生动作与起点选择 | CVRP TopK、后续 greedy 动作由状态和策略产生。它们可能难算，但不能仅凭“选择器没有这张动作表”宣布信息论遗漏。 |
| 动作采样 | 可在概念上写成动作由当前状态与预先随机输入 U_m 共同生成。实际采样动作、前缀和成本是计算结果，不能变成 query 前向输入。 |
| 未知历史生命周期 | RNG 消耗位置、先前调用影响及相关进程状态均可能未恢复。不能凭一个 seed 声称重建，也不能把缓存的查询答案包装成状态元数据。 |

设 O 是在做选择前合法可知、并与实际部署绑定的那部分条件。其余条件只能作为潜变量处理。全池成本向量 C 的联合条件分布决定 winner Y；Y 沿用冻结 native/FP64 ind 与原 tie 规则，不在此用 FP32 argmin 重做标签。对同一信息集合 I=(X,O)，三个理想决策分别是：

$$
a_{\rm Top1}=\arg\max_{m\in M(X)}\Pr(Y=m\mid I),
\qquad a_{\rm cost}=\arg\min_{m\in M(X)}\mathbb E[C_m\mid I],
$$

$$
a_{\rm regret}=\arg\min_{m\in M(X)}\mathbb E[(C_m-C_*)/C_*\mid I],
\qquad C_*=\min_{k\in M(X)}C_k>0.
$$

这些是损失定义的推导，不是新训练目标推荐。冠军概率、期望成本与含随机 Oracle 分母的 regret 不等价；各候选成本边际也未必确定全池冠军概率，不能无依据把候选噪声当作独立。R71 的联合成本差分布、R116 的排序后验已有近邻先例，换一个概率名称不能成为新方向。

**正频率 winner 可以从不成为最优分类决策，但条件必须说清。** 纯逻辑例子：对每个可观察 X，三个候选的冠军概率都为(0.45,0.35,0.20)，则第二候选有35%的 winner，却从不成为概率 argmax。反之，如果完整 X 和固定配方已确定所有执行与 tie，且某候选在正概率的实例区域获胜，那么完整信息的 Bayes 规则会在该区域选择它。有限网络零选择并不推翻后一事实。[历史推导背景](../deep_direction_review_20261023/REPORT.md)

因此须分清三层：未观察到影响结果的 Z，可能留下条件不确定性；表示 φ(X,O) 合并了不同执行对象，属于表示限制；模型未学会使用已在输入中的信号，还可能是函数类、有限样本或优化问题。三者均不能由约71%的当前准确率单独识别。确定性的 TopK 或角色标记可以改变有限计算的易学性，却不增加完整 X 的信息；本稿没有估计项目的 Bayes 上限。

**三、哪一种对称性才应保留？**

这里的推导针对带执行条件的对象，而非只针对最优组合解。令 P_π 为合法节点重编号，T_π Z 为与之对应的角色及随机实现变换。如果它们确实表示同一次物理计算，理想语义应满足：

$$
F_m(P_\pi X,T_\pi Z_m;D_m)=F_m(X,Z_m;D_m).
$$

相应的标量预测应保留这种联合不变性；节点预测应随节点重编号等变。这不是本项目实现的数值认证：adapter 的合法输入、tie-break、噪声耦合和浮点操作均须与“同一次计算”相容。

| 操作 | 应如何理解 |
| --- | --- |
| 重新编号，同时携带物理节点的角色 | 表示同一带角色对象，才有上述不变性要求。 |
| 图不变，将角色从物理节点 a 改给 b | 改变执行条件；原问题最优值可能相同，有限 solver 成本无需相同。 |
| 重排数组后再次把 slot0 当起点 | 若换了物理起点，就是第二种操作；若 adapter 强制 depot/起点在固定槽位，则携带标记但违反接口也不是合法比较。 |
| 重抽随机角色，但保持抽样分布 | 是另一次实现，最多讨论分布不变，不能要求逐实例成本相等。 |

ATSP 还需保留行与列表示同一城市的对应。MatNet 通用二部矩阵编码支持的行列重排，不能直接充当 ATSP 任意独立重排的合法性证明。带资源任务的类型槽位和 depot 约定同样不能从裸图同构推出。

对于随机执行，若条件分布满足 Q_m(·|P_πX)=(T_π)_#Q_m(·|X)，并且上述语义关系成立，才能推得成本的**分布**不变。符号 # 表示随重编号搬运随机条件。各候选分别满足边际关系仍不足以保证 winner 分布不变，后者需要联合条件分布相容。相同 seed 不保证相同物理实现：随机数可能按数组槽位分配；即使重用同一个均匀数，重新排序后的累积概率采样也可能选到不同物理节点。

所以，应保留的是“无意义编号”的不变性，不能把“实际角色赋值”也一并消掉；同时不能把全部节点次序都强行当作有意义角色。当前 R94B 已携带 TSP node0，正是前者的现有实现事实；本稿不提出重复位置编码。原始 optimum 的不变性也不保证固定次数搜索、解码或局部改进的输出不变。

**四、三篇直接阅读的原文支持什么？**

**P01 · MatNet，arXiv:2106.11113v2，2021-10-26。** §3.1–3.3 用二部更新及混合注意力处理矩阵，并以零向量和随机分配的不同 one-hot 启动两类节点。§4 的 ATSP 推理采用多起点采样；§4.1、表4.1及附录C、表C.1比较重抽初始角色的增广与复用编码的采样。它直接支持“初始角色与动作采样不同，角色实现能影响有限求解”。[原文 PDF，pp.3–7、16](https://arxiv.org/pdf/2106.11113v2)

本文迁移边界：原文的 ×128 选优不等于当前生产归并。Sol 给定事实是生产执行128个增广、最终只在 orientation0 上选最佳 start；本文按该配方定义 F_m，不将论文中的跨增广最优偷偷替换进去。原文不解释 R118 的历史成本差，也没有证明给选择器提供角色就可预测候选胜负。

**P02 · POMO，NeurIPS 2020 正式论文 PDF。** §3、§4.1–4.3 区分等价解序列、多起点及增广；§5 的推理说明、§5.1和表2比较单轨迹、多起点与增广。§5.2 起始讨论明确指出 CVRP 并非每个客户都能作为某最优路线的首客户，不能把 TSP 的循环对称性直接搬来；表3及随后的说明给出 CVRP 比较。[原文 PDF，pp.3–9 的上述部分](https://proceedings.neurips.cc/paper_files/paper/2020/file/f231f2107df69eab0a3862d50018a9b2-Paper.pdf)

本文迁移边界：论文的推理差异支持“同一最优值并不抹平有限解码差异”，没有认证本项目的起点规则。当前 RELD_CVRP 的 TopK 事实来自 Sol，不能被 POMO 原文的全客户起点策略覆盖。

**P03 · Relational Pooling，ICML 2019／PMLR 97 正式版本。** §2及§2.1–2.2 对图与属性同步重排，给出理想置换平均与 ID 增广；§2.3.2 明确有限随机近似只近似不变，且“先平均输出再取损失”与“平均损失”不同。§4.1 的 CSL 图分类和表1展示其表达能力对照。[原文 PDF，pp.1–5 的指定小节、p.7](https://proceedings.mlr.press/v97/murphy19a/murphy19a.pdf)

本文迁移边界：表达能力定理有离散属性、足够表达力及理想平均等前提；本轮未读补充证明。图分类收益不是 solver 选择收益；随机 ID 平均不是恢复某次真实执行角色，也不能提供当前全池 winner 的可学性保证。

三篇论文共同约束了问题的写法，没有给出 whole18 的正面迁移证据。书目、精确阅读范围及未读部分记录于 [sources.csv](sources.csv)，不是穷尽检索或新颖性认证。

**五、执行条件怎样才能合法地属于学习对象？**

有意义的条件化对象是每个合法候选的“实例、已知部署、绑定的物理角色及合法预先随机输入”，并预测这些条件怎样影响其后续决策相关行为。方法名描述一般规律；全局位置标签不能指定每候选的实际角色；参考激活是某次输入定义计算；输出偏置只改变偏好。它们与实际执行条件的绑定不是同一件事。但是，**目标定义正确不等于新增了有用特征，更不等于新架构或新研究范式已经成立。** R57 已提出执行角色问题。

允许的科学计算边界是：从 X 与合法已知条件出发，预测角色对节点、连接或资源状态演化的影响，再用于完整合法池的选择。真实 TRAIN 原生状态可以成为监督，query 侧只能使用允许输入和自身预测；不提供 query 的动作、轨迹、成本、winner 或 holdout 答案。不在此指定层、batch、时长或实施方案，也不恢复历史过程储备已缺失的“小而充分状态”证明。

条件要同时与**标签**和**将被执行的候选**绑定。若某次随机赋值在选择前已合法确定，选中该候选后应消费同一实现，并保持原 start、增广及归并规则；若赋值在选择之后才抽取，选择时只能对它边缘化。看到分数后重抽、挑 seed 或扩大随机实现集合，会改变决策对象。seed 只有在 RNG、状态、调用顺序及实现相容时才可能重建 draws；直接把整数喂给网络并无可学习性依据。

旧标签写作 C_m^old=F_m(X,Z_m^old)。新捕获给出 Z_m^fresh 及其新执行，**不能据此把 (X,Z_m^fresh,C_m^old) 当作真实实现配对**。只恢复部分变量时，可对未恢复部分边缘化，但仍须有真实对应的已观察变量；不允许用新 draws 冒充。单个标量存在多对一映射，数值碰巧匹配也不恢复旧 Z。新执行的观测可以描述新行为，却不自动继承冻结标签的全池胜负，也不能替换该标签。

**六、唯一储备与一个决定性科学对照**

**唯一候选储备：与部署绑定的执行条件下，学习决策相关的候选行为。状态：未就绪，非新主线。** 这是旧原生过程储备的边界修正，不另开 MATNET 或 ReLD 二分类方向。它的命题必须面向18题各自完整合法候选池，关注逐题及等权 ALL 的真实选择与误选成本；观测不到过程的候选仍参与竞争，不能换成已覆盖子池的 winner。

**最强反对理由：当前没有展示一种同时可合法获得、与原标签对应、经济可预测且能改变全池竞争的条件。** TSP 已知锚点已有；CVRP TopK 是内生计算；MATNET 新角色虽真实，却没有旧实现配对。即使拿到角色，其对最终成本的作用仍可能需要近乎完整求解才能算出。18/89项部署和144个实例无法承担全平台解释。记录更多过程行也不解除这个缺口。

**最近失败先例是 R117。** 它已经触及比浅 encoder 更深的原生参考计算而未兑现匹配的联合收益，故储备必须解释实际绑定为何比已有参考条件多出可泛化证据。R88→R94B 的现成锚点又排除了“再加 node0”；R113 的过程反例仍约束状态演化说法。早期两轮报告记载的候选工作区、联合成本分布及学习机制不因改名消失。[第一轮：§3、§6及历史表](../deep_direction_review_20261023/REPORT.md)；[第二轮：§6、§7.3–7.4](../deep_direction_review_v2_20261023/REPORT.md)。第二轮关于旧基线未表示 node0 的表述，不能用来覆盖本次 Sol 对当前 R94B 的修正。

**唯一决定性科学对照：对同一批确有真实实现配对、全池终局目标相同的对象，比较“条件化于实际已绑定条件”与“只保留当前已知输入、对额外条件边缘化”的决策。** 两者都保留现有 TSP 锚点和完整原始输入，且具有相当的表达与学习机会；后者不是故意错绑或乱序的弱对照。额外 O 必须在推理前合法可用，前者不得用真实查询过程补全剩余状态。这只定义要区分的科学解释，不是采集、预算或开跑计划。

若条件化只改善状态拟合、单候选成本或 MATNET 命中，而未改善完整竞争中的正确选择与误选代价，它不支持 whole18 主张；若只有改变随机实现或使用查询答案才改善，则比较对象已变。若有效性仅覆盖部分部署，结论必须限定到该覆盖，不能由全池评分反推全池条件均被解释。即使成功，也只支持这些合法条件在有限学习中的用途，不证明它们导致了历史错误。**当前没有忠实的旧 MATNET 配对，R118 资产不足以声称这一对照已经具备或完成。**

本轮至此停止：新主方向为零，保留一项未就绪的条件化储备。冻结 new90k/whole18、81000/4500/4500 划分、native/FP64 标签和删减候选池不变；R58 继续延期。历史 TRAIN 上下文仍须 self/base 排除，TEST 已参与研发，不称盲测。本轮只完成三个所属科学文件；机械 PDF 和任何后续执行决定由 Sol 负责，未生成实验、代码改动或新增标签。
