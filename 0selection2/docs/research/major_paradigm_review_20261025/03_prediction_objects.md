## 2. 首先区分要作出的三个决策

令`X`为合法实例输入，`D`为允许的历史TRAIN，`M`为合法候选池，`C_m`为候选原生成本，`C_* = min_m C_m > 0`，`Y`为冻结的native winner。各题分别有：

\[
\delta_{\mathrm{Top1}}=\arg\max_m P(Y=m\mid X,D),\qquad
\delta_{\mathrm{cost}}=\arg\min_m E[C_m\mid X,D],
\]
\[
\delta_{\mathrm{regret}}=\arg\min_m E[C_m/C_*\mid X,D].
\]

第三项不是均值之比；减去1或乘100不改变其最优动作。联合依赖可能影响冠军事件，但最小化期望原生成本只需边际均值；直接学习逐方法相对regret均值，也不必先恢复完整联合成本分布，R98已走过这条路。更准确的成本预测不等于更准确的冠军预测。

**两两胜率不识别冠军后验。**用`ABC`表示A最好、C最差。分布P在`ABC,CBA,ACB,BCA`上各取1/4；分布Q在`ACB,BCA,BAC,CAB`上各取1/4。两者每一对的胜率都为1/2，但冠军概率分别是`(1/2,1/4,1/4)`和`(1/4,1/2,1/4)`。因此Borda、平均pair胜率以及无额外假设的pairwise coupling都不能替代冠军边缘概率。边际成本分布正确，也不保证联合冠军事件正确。

**固定信息下究竟能学到什么？**`g_theta(X,D)`及其独立随机采样不增加真实query观察；它们改变计算组织和归纳偏置。不能据此否定大架构，也不能把模型模拟当成新证据。若部署及种子完全确定，真实成本在给定完整输入后是确定函数；模型不确定性不自动等于solver随机性。

| 拟学习对象 | 现有终局成本的支持范围 | 不能冒称已识别的部分 |
| --- | --- | --- |
| 完整排序、成本差向量 | 每个已有TRAIN实例可计算；全池排序提供比winner或pair汇总更完整的监督 | 每个新X的条件分布仍依赖跨实例共享假设；一个观测不能唯一决定它。 |
| 固定部署的响应函数 | 已观测输入处有函数值，可学习统计泛化 | 未变化的预算、随机种子、checkpoint轴上的响应，以及因果干预效果。 |
| 原生解结构、搜索过程 | 若已有对应结构标签，可监督其中被记录的对象 | 单个终局成本通常对应多种解和轨迹，不能反演唯一过程；无约束潜变量名称不提供语义依据。 |

这不是“一个X只有一个标签，所以任何条件分布都不可学”的断言。问题是哪些结构可由统计共享约束，哪些需要额外观测；潜变量坐标不唯一也不必然损害其预测分布。

## 4. 方向一：完整排序过程，而不是又一个排序loss

### 4.1 核心替换与可学习依据

把图级单次评分替换成**候选子集状态空间上的反向淘汰过程**。学习对象是从最差到最好的一整个排列，而最终动作是该排列分布的冠军边缘概率。排序监督直接来自现有终局成本，不需要过程标签。

数据流：`原始实例 -> 一次共享图编码H -> 每个合法子集S的候选交互状态 -> 淘汰概率 -> 所有路径的概率传播 -> 冠军边缘 -> 一个原候选`。

令`e_theta(j|X,S)`为在剩余集合S中下一步淘汰j的概率，`pi=(pi_1,...,pi_K)`按从差到好排列，`S_r=M\{pi_1,...,pi_(r-1)}`：

\[
P_\theta(\pi\mid X)=\prod_{r=1}^{K-1}e_\theta(\pi_r\mid X,S_r).
\]

概率分解借鉴[P01 Choosing to Rank](https://arxiv.org/pdf/1809.05139v2)关于repeated elimination的规范化构造；下述图条件子集网络及冠军动态规划是本文的项目提案，不是该论文已验证的选择器。

推理不贪心淘汰，不取概率最大的完整排列的第一名。由大集合到小集合累计：

\[
w(M)=1,\qquad w(S\setminus\{j\})\mathrel{+}=w(S)e_\theta(j\mid X,S),
\qquad p_m=w(\{m\}),\qquad\delta=\arg\max_m p_m.
\]

若从冠军开始自回归，后续顺序通常不参与冠军边缘推理；反向构造使各级候选关系实际参与最终选择。这里的S是内部状态，不是更改部署候选池，更不是实际运行候选后排除输家。

**标签隔离必须贯彻到训练计算。**事先按候选ID枚举全部子集，网络前向不读取真实成本决定下一步S；真实排序只在loss中索引相应路径。严格并列可对兼容排列集合`Omega(C,Y)`取`-log sum_pi P_theta(pi|X)`，保留冻结native winner规则。若该规则与严格成本比较不相容，须显式标记，而非静默改成FP32 argmin或人为造序。枚举未被监督充分覆盖的子集不会自动产生新信息。

### 4.2 为什么不是R71、R100或R111

R71从连续联合密度积分出冠军，本方向从离散完整序关系精确边缘化出冠军：**差异是所拟合的对象及推理组织，不是第一次引入候选相关性。**它主动丢弃成本幅度，避免用密度拟合大量与冠军无关的变化，也因此不能单凭排序对象最小化期望成本。

R100的pair概率不能重建完整序关系分布；R111是固定家族树；[R85-D](/public/home/shiys/0selection2/code/V4/r85_objectives.py:376)已有标签无关随机子集辅助CE，但不在部署阶段组合所有子集路径。新提案的关键是动态子集交互与全路径决策一起存在，不是把训练辅助项换成listwise loss。

固定utility的softmax有IIA限制，但**softmax本身不禁止候选互依**，现有候选token也不是天然独立。[P02 CDM](https://proceedings.mlr.press/v97/seshadri19a/seshadri19a.pdf)说明集合相关效用及其识别条件；不能把人类选择中的context effect当成删除竞争者会改变solver真实成本。这里建模的是条件序事件。

### 4.3 最强反对、资源与决定性对照

全排序可能把容量浪费在远离冠军的尾部；罕见子集监督不足；以S作为充分状态的Markov假设排除了依赖已淘汰顺序的过程。放弃该假设则不能如此合并路径。因此它不是严格优于R71的通用分布类。[P03 Learning Rich Rankings](https://papers.nips.cc/paper_files/paper/2020/file/6affee954d76859baa2800e1c49e2c5d-Paper.pdf)第5.3节的反方尤其重要：contextual ranking在所分析选举数据上的位置似然收益出现在靠前但并非第一位；不能把整榜NLL改善宣传为Top1收益。

资源随K指数增长：最多`2^K-1`个状态，概率传播`O(K*2^K)`，子集内attention还可能是`O(K^2*2^K)`；图编码可共享，但不能称为免费小头。没有新增query信息，只是不同的有限样本归纳偏置。它可能在全18中学习“同一个候选面对不同剩余竞争组合的相对位置”，但这是否恢复真实漏选仍是假说，不靠提高某方法选择率证明。

**一个决定性对照：**共享输入编码、完整排序监督和同一动态规划，使用同构同容量的候选交互网络，比较“每个S重新计算候选交互”与“网络始终处理全池，只将固定候选logit按S重新归一化”。这隔离了动态条件对象，而非额外标签或换决策规则。若动态模型仅改善尾部排序/NLL，不能带来全18 native Top1的净正确改善，或选择收益伴随不可接受的成本退化，就停止这条特定机制；不以更多淘汰顺序或小权重搜索延续。另与锁定完整参考模型比较实际效用，不能只赢弱化内部对照。

## 5. 方向二：条件响应函数，而不是泛称“贝叶斯联合生成”

### 5.1 真正不同的对象应是什么

对象可定义为固定部署下的函数`F:(X,m)->C_m`，历史上下文`D_q={(X_i,m,C_im)}`只含合法TRAIN。数据流为`上下文集合编码 + query输入/候选描述 -> 条件函数表示 -> 同一query的联合响应样本 -> 冠军积分或预先指定的成本决策 -> 一个方法`。

\[
\widetilde{\boldsymbol C}^{(s)}\sim P_\theta(\boldsymbol C_q\mid X_q,D_q),\qquad
\widehat p_m=\frac1S\sum_s\mathbf1\{m=\operatorname{winner}(\widetilde{\boldsymbol C}^{(s)})\}.
\]

同一次联合样本中的候选不能独立重排后仍称原联合分布。最终取估计冠军边缘的argmax；随机抽一个样本的winner不等于Top1的Bayes决策。

[P04 TNP](https://arxiv.org/html/2207.04179v2)提供历史上下文条件化、目标序列及非对角联合输出的具体组织；[P05 Autoregressive CNP](https://arxiv.org/pdf/2303.14468)将已生成目标重新作为上下文，以此产生非高斯相关性。这些是可实现机制，不是“一个潜变量表示算法世界”的命名。后者明确存在目标顺序及边缘一致性问题；[P06 Neural Diffusion Processes](https://proceedings.mlr.press/v202/dutordoir23a/dutordoir23a.pdf)以集合对称结构建模函数值，但也不自动保证Kolmogorov边缘一致性。

### 5.2 为什么现在不优先

当目标仅是同一X的K个终局数值，R71已经学习其联合关系；变化主要是历史上下文条件化及更灵活的密度族。R47已有训练过的历史行为记忆，R97/98/100已有整套TRAIN的winner/gap/pair上下文。它们没有穷尽函数学习，但“全协方差换flow/diffusion”不足以解释为什么能解决其失败。

18个固定任务及其随机遮罩不等于大量独立响应函数。若声称学到预算、种子或跨部署变化规律，必须有对应轴上的标签，不能从单预算终局表识别。若AR/扩散训练把当前样本真实成本或加噪成本送入预测前向，也超出现行标签隔离约定，必须另行授权；仅历史上下文进入前向、目标只进入联合似然的解码器没有这一额外问题。

资源包括上下文读取、目标间交互及每次抽样的迭代解码；普通密集attention为序列长度平方，AR还随候选数串行。大量模拟样本只降低模型积分误差，不增加真实知识。最强反对意见不是密度太简单，而是更复杂的密度可能继续精确拟合无助于决策的公共波动，或者用未识别的潜因子解释同一表格。

**决定性科学对照与停止条件：**若未来有充分理由重开此路线，在保持预测边际不变时，将同一query的联合样本列独立重配，破坏候选耦合，再比较冠军决策。它是模型诊断，不是对真实数据作因果干预。若保留耦合只改善联合NLL而不改善native冠军决策，则“联合依赖是缺失关键”不获支持，应停止为此增加生成复杂度。若两个版本都差，也不能据此证明真实依赖不存在。

**本轮拒绝将该路线列为优先启动项。**只有明确增加跨场景/部署函数监督，或发现可验证而非命名的函数一致性缺口，才值得与专题04重新合并讨论；不是再默认一次local ridge。

## 6. 方向三：预测固定候选会返回什么，而非只预测多少钱

### 6.1 完整结果模拟器

真正较大的替换是：对每个固定候选的部署契约，联合预测其终局解结构`Z_m`，必要时显式演化其状态；用原生目标函数连接结构和成本。部署契约包括checkpoint、增广、解码及repair等实际行为，不能只给一个方法家族名。

\[
\boldsymbol Z\sim P_\theta(Z_1,\ldots,Z_K\mid X,\mathcal A),\qquad
\widetilde C_m=c_{\mathrm{native}}(X,Z_m),\qquad
p_m=P(m=\operatorname{winner}(\widetilde{\boldsymbol C})).
\]

数据流：`输入图/约束 + 候选契约 -> 跨候选共享及私有结构状态 -> 预测状态转移/终局结构 -> 原生合法性与成本评价 -> 联合冠军边缘 -> 选择一个原候选`。若包含过程，当前实例真实中间状态也不得teacher-force进入前向；需要模型自行滚动，监督只用于比较预测状态。

与R71的实质差异在于**结构生成和原生评价是决策必经路径**，而不只是附加loss。要学的是“候选m实际将返回的解”，不是“X的一个好解”。若所有分支都学到相同的近优结构，求解质量可能很好，选择信息却消失。仅有终局成本不足以识别这条结构/过程链；须新增或确认存在对齐的TRAIN结构标签，不能用无约束潜变量代替。

### 6.2 论文究竟支持哪一段

[P07 Neural Execution of Graph Algorithms](https://arxiv.org/pdf/1910.10593v2)给出编码器、共享processor、解码器和终止预测的具体执行链，监督对象是算法状态。[P08 CLRS](https://proceedings.mlr.press/v162/velickovic22a/velickovic22a.pdf)用typed probes区分输入、hints和输出，但其任务选择排除了NP-hard问题及近似算法；这些证据不直接覆盖预算化神经routing部署。

[P09 DIFUSCO](https://proceedings.neurips.cc/paper_files/paper/2023/file/0ba520d93c3df592c83a611961314c98-Paper-Conference.pdf)把二元解结构作为生成对象，同时需要额外解码/搜索获得可行解。因此“生成图”不自动等于“合法solver结果”，其论文求解成绩不能预言选择器增益。[P10 MTL-KD](https://arxiv.org/html/2506.02935v1)在学生访问的状态上调用任务教师蒸馏策略，说明动态状态和教师响应可被监督；它训练的是统一求解器，不是同一实例多个固定部署的结果模拟器，也不是免费获得原生教师标签。本次实际复用了[本地PDF](/public/home/shiys/0selection2/literature/downloads/2506.02935.pdf)第3至6页。

### 6.3 历史反方、额外授权与可证伪点

R54已有结构辅助预测；[R55](/public/home/shiys/0selection2/code/V4/r55_model.py)更已尝试两ReLD的计费边差结构瓶颈，距离加权的结构差直接决定成本差，不能说项目从没让结构参与决策。旧报告显示结构差趋近零且选择未获益。新路线的区别是全合法池、候选特定的完整相容结构/过程及联合反应，不是把R55边头做大；历史阴性仍强烈提醒：结构损失可能被公共路线掩盖，决定相对胜负的微小结构差最难学。

资源可能达到每候选每步`O(n^2)`的边状态，另有轨迹存储与原生评价，必须计入选择开销。训练需要同冻结TRAIN、同候选部署契约的结构或轨迹、终局成本与稳定ID对齐；本次未证明这些资产在全18的当前81k上齐备，不能把旧R54/R55资产当现成全覆盖。

**需额外授权的两件事不能混淆：**新增训练过程标签不等于新增query观察；但是在query上生成并修复K套完整可行解，可能已经在做多方法求解，不能因称为“模拟器”就算零solver成本。若实际执行多个原生候选后择优，则明确改变原任务；若只生成软结构，则必须承认可行性与原生评价链不再自动成立。部署边界未澄清前，不提出执行。共同随机潜变量也不能凭空代表真实solver之间的种子耦合。

**一个决定性对照：**在获得相同新增结构监督后，比较“结构仅作辅助任务、直接选择”与“结构必须经原生评价形成选择”，保持输入及编码器条件可比。只有后者改善候选相对成本/冠军净正确，才支持改变推理对象，而不只是多了标签。若结构准确率提高但相对胜负不改善、仅在真实状态teacher forcing下有效，或模拟成本接近执行候选池，就停止这条结果模拟假说，不以再加扩散步数拖延结论。

## 7. 给综合者的明确答复

终局成本确实能提供完整排序和固定部署响应值；它不能唯一反演解结构、轨迹或未观察的预算响应。前者值得研究新的推理归纳偏置，后者必须承认监督缺口。R71已是联合成本差到冠军后验的完整路线，新的科学主张不能再停留在“联合”“生成”“考虑相关性”这些词上。

本专题保留的现有信息路线，是**不拟合连续成本密度的序关系过程及冠军全路径边缘化**；新增授权路线，是**候选特定结果结构成为决策必经对象**。前者没有新query信息，后者主要增加训练监督而不自动增加query信息。二者都不使用pair胜率冒充冠军后验，也不承诺同时优化Top1、mean_cost和actual regret。

所有将来检验均须先固定主决策目标与唯一checkpoint/推理规则，按全18等权报告净正确、成本及regret，并与VAL并列；旧TEST已经参与研发，不能宣称盲测。本文不规定预算、启动命令或新划分。若核心对照为负，停止对应机制，不推导71%是天花板，也不把方向偷偷收缩回罕见方法微调。
