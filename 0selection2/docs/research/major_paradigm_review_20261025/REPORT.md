# 如何跳出局部修补：重建组合状态、响应规律与可执行表示

2026-10-25。科学综合定稿。对象是当前冻结数据上的全18题、固定合法候选池、最终选择一个方法。本稿提出研究路线，不是已验证的性能改进，也不授权任何新实验。

## 执行摘要

### 直答：下一步应该“大改”什么？

**不再主要修改同一套编码器后的评分方式，而改变系统必须保存、组合和学习的对象。** 本轮保留三条主线：把区域摘要改成有条件的接口状态；把独立样本训练改成候选响应规律学习；把静态预训练向量改成推理时仍在执行的计算规则。三条可以独立成立，不要求先堆成一个超级模型，也不要求先证明旧网络在理论上绝无表达能力。

| 优先次序与主线 | 真正替换的对象 | 现有信息层 | 新授权层 |
| --- | --- | --- | --- |
| **1. 区域接口组合表示** | 从“一个区域一个摘要”改为“区域在不同边界条件下的状态表”，跨尺度双向组合 | 原始输入、现有TRAIN监督；是当前条件下首先值得考虑的完整架构重构 | 若要求接口具有真实子问题成本或可行性含义，需要对应中间监督 |
| **2. 候选响应函数学习** | 从独立实例的winner，改为学习“条件变化怎样使不同候选相对受益” | 原始图与合法TRAIN上下文共同学习跨环境推断；没有新增独立信息 | 优先考虑有来源的成对干预及全池真实响应标签，构造更可信的学习任务 |
| **3. 可执行算法表示** | 从迁移静态encoder，改为迁移类型化状态转移，并在选择时继续运行 | 可研究潜在状态机，但不能冒称学到了真实算法过程；不把弱化版列为冻结层首选 | 明确程序及其状态监督、可组合过程预训练；query只反馈模型预测状态 |

**这个排序不是四位作者的平均票。** 01的区域接口提案被保留为固定信息层首选。02和04的函数先验、任务族元学习归入同一主线，而不是两份相互验证的证据。对新增训练信息，本综合优先考虑04的真实相对响应语料，排在02的通用算法过程库之前：前者直接约束当前候选竞争，后者还需跨过“执行程序更准，所以候选排序更准”这一额外桥梁。03的反向淘汰确实改变推理，仍不列入前三主线，因为其主要状态是候选子集，尚未重建实例内部的组合表示或表示获取方式。

三条路线分别回答不同问题：

```text
路线1：原始实例 -> 条件接口状态 -> 跨区域组合 -> 全池比较 -> 一个方法
路线2：历史响应族 + 原始实例 -> 条件函数状态 -> 预测相对响应 -> 一个方法
路线3：原始实例 -> 自初始化算法状态 -> 学得的转移规则 -> 一个方法
```

### 为什么不是换名字重做历史？

R63已有候选节点递归，R92已有层级图，R107已有连通短路径；新意不能只是“多尺度、高阶、迭代”。路线1要求**边界条件在合并之前不被平均掉，且父区域的外部条件会反向改变子区域状态**。R47已有FULL18可训练记忆，R97/98/100已有完整TRAIN上下文；路线2要求**从原始结构和响应的绑定中学习跨场景推断规则**，授权强版本还改变训练数据的基本单位，而不只是换检索器。R54/55/61已有结构监督，R94/101/106已有表示迁移；路线3要求**迁移后的处理器继续执行并反馈自己的预测状态**，不是再换一个donor或静态hint。

最大的共同风险也很清楚：这些新对象可能只更好地描述所有候选共同面对的困难，而没有学会候选之间的差异。因此，区域表示需要候选条件读出；响应学习需要绝对名次锚点和原生winner监督；算法预训练需要真实选择任务的下游桥梁。**辅助对象学得漂亮，不是选择成功。**

### 相比上一轮，结论改变在哪里？

本轮正式撤回“局部ridge是唯一值得新增的机制”和“等待在途结果是科研主线”的排序。局部函数拟合仍可作特定比较对象，但其闭式解清楚，不等于它比整体重构更有科学根据。R109/R111仍由原线程处理，不因本研究暂停或变更，也不成为上述路线的前置门槛。

没有新增项目实验结果。本轮新增的是对计算对象、训练信息和历史反证范围的重新划分。R105-R110的已完成证据仍然约束提案，R110的完成状态不再沿用旧文末的将来时；也不将它们扩张成71%的上限证明。历史上R94的表示迁移、R77的独立样本扩充有有限正证据，不能把整个研究写成“全部模型都严重过拟合、所有方向都失败”。

**建议是有限而非保守地循环：**固定信息先考虑路线1；若愿意另议训练信息授权，先考虑路线2的真实成对响应，再考虑路线3的过程语料。每条路线后面给出能决定是否继续的科学对照，而不是先安排一串审计才能研究。最终看同一完整模型的全18 Top1、真实纠正、丢失旧正确、新误选、mean_cost与actual regret，不用提高某方法选择次数或答案感知union替代净收益。论文和同族LLM综合均不构成独立复现实证。

## 1. 先改变研究问题，而不是遗忘历史

### 1.1 上轮收缩的原因及本轮纠正

上轮聚焦“最近失败以后，还剩哪一个与历史不同、容易精确定义的小机制”，因而将显式局部拟合留到最后。这有助于阻止重复包装，却把**局部可说明性**放在了**改变整个学习系统的潜力**之前。更大的方案被要求先证明旧模型无法表达它；较小的方案只要方程不同就能留下。这一门槛并不对称。

### 1.3 仍然值得研究的中心假说

用一个非唯一的分解说明问题：

\[
C_m(X)=g(X)+\epsilon_m(X),\qquad
C_m(X)-C_n(X)=\epsilon_m(X)-\epsilon_n(X).
\]

`g`表示共同变化，`epsilon_m`表示候选相对偏离；这不是已识别的因果模型。学好几何、可行性或最优值，可能主要学准`g`。新的宏观系统必须给出一条学习路径，使组合条件或场景变化能够形成**不同候选的不同响应**。

三条路线不以某个零选择方法为唯一对象。此前R94B参照中，固定36个零/近零组约占错误的19.46%，其余错误占80.54%；这是特定历史模型的诊断，不是新模型的分解。只围绕两种ReLD或单个LEHD修补，无法覆盖全部问题。具体依据仍是[上轮全景与ALL分析](/public/home/shiys/0selection2/docs/research/comprehensive_direction_review_20261025/REPORT.md)。

## 2. 保留任务边界，放开计算形式

### 2.1 三条路线共同的决策终点

令`X`为允许的原始实例输入，`t`为任务语义，`M_t`为合法候选池，`D`为允许的历史TRAIN，`Y`为保存的native/FP64 ind winner。主决策路径统一为

\[
\widehat p_\theta(m\mid X,D,t),\qquad
\widehat m=\arg\max_{m\in M_t}\widehat p_\theta(m\mid X,D,t).
\]

此处是模型预测，不宣称等于真实冠军后验。直接以原生winner训练的全池分类读出即可实现，不要求先恢复整个联合成本密度。现有成本可以监督响应或结构，但`argmin E[C_m]`、`argmin E[C_m/C_*]`和最可能winner通常不是同一个动作。具体Top1与成本取舍应明说，不靠输出对象的名称消除。

纯输入状态`S=f_theta(X,D)`不会创造新的query观察。这不妨碍它用更合适的计算分解提高有限样本学习效率；“信息集合没变”和“模型已将信息用尽”不是同一命题。相反，额外执行原生候选获得的真实状态，不能因也是输入的函数就算成免费表示。

### 2.2 信息授权分层

| 层级 | 可以研究的改变 | 不能暗中带入的内容 |
| --- | --- | --- |
| 冻结信息 | 重建整个神经状态空间、训练单位和条件推断；使用已授权的排除式TRAIN上下文 | 当前query或同base关联副本的标签；VAL/TEST/LIB标签；新solver观察 |
| 新训练资料 | 新的无标签输入、类型化过程监督、成对干预后的真实候选响应 | 将自动生成标签称为已获授权；将玩具程序winner当作原生候选winner |
| 新部署观察 | 另议可见场景信息、受限轨迹或松弛探测 | 将新增观察、时间和未选候选支出隐藏在静态选择指标中 |
| 新任务 | 直接返回新解、多原生方法执行后择优、调度候选预算 | 用新任务成绩替代当前固定池单方法选择成绩 |

本稿只建议研究，不执行上述任何变更。当前18题每题81k/4.5k/4.5k、logical batch1024、seed2与候选规则保留；不恢复已删候选，不合并两种ReLD成本，不重开R58。历史TRAIN例外严格排除当前实例及同基础实例副本。新训练语料若另获授权，应作为独立版本，不能覆盖冻结表。

## 3. 主线一：区域接口组合网络

### 3.1 从区域摘要改成条件响应表

普通层级编码把区域内节点和关系压成一个向量，再向上聚合。这里改成：**一个区域在不同入口、出口及外部资源条件下，保存不同状态，并在更大区域的组合中持续更新。** 同一片节点在不同外部条件下可能造成不同冲突；只有先保留这些条件，后续候选读出才有机会区分谁更容易处理哪一种组合。

```text
输入：坐标或有向成本矩阵 + 原始需求/时间窗 + 任务语义 + 合法候选
  -> 仅由输入形成区域层级，保留细粒度及跨区域关系
  -> 初始化 H_R(sigma)：区域R在边界条件sigma下的潜在状态
  -> 子区域按兼容接口组合成父区域状态
  -> 父区域与兄弟区域的条件向下反馈
  -> 候选条件读出完整的多尺度接口状态
  -> native winner监督的全池概率 -> 唯一argmax方法
```

`sigma`是索引而不是答案。最简单的近似含进入端口、离开端口和资源条件；需要多次穿越区域时，单进单出可能不足，可以将边界配对模板作为状态定义的一部分。不能只因增加模板就宣称已保留完整路径空间，也不在本报告规定端口或模板的执行数量。

TSP可以没有资源轴；ATSP必须保留方向性，区域构造不能硬套欧氏网格；带容量、时间窗或B语义的问题使用各自的条件类型，不能把signed-load与classical-B压成同一个“真实载荷”。共享的是接口组合系统，不是所有问题的物理语义。

### 3.2 实际学习与计算的对象

设`U,V`为子区域，`D_UV`保留跨区方向信息，`chi_t`为任务语义，`K(sigma)`是索引层面允许组合的子签名集合：

\[
H_R(\sigma)=U_\theta\!\left(H_R^0(\sigma),
\operatorname{Agg}_{(\sigma_U,\sigma_V)\in\mathcal K(\sigma)}
\Phi_\theta(H_U(\sigma_U),H_V(\sigma_V),D_{UV},\chi_t)\right).
\]

向下通道再用父区域条件和兄弟区域状态更新同一个`H_U(sigma_U)`。这是双向、条件保持的计算，不是合并一次后就丢掉边界对应。`K`不冒充完整路线可行性判定；潜状态也不冒充子问题最优值。若一个所谓接口网络最终仍在每层对条件轴求均值，便退回了本路线要比较的对象。

最终分数为

\[
u_m=b_m(t)+G_\theta(\{H_R(\sigma)\}_{R,\sigma},d_m),
\qquad \widehat m=\arg\max_{m\in M_t}u_m.
\]

`d_m`保留固定候选身份和已知部署语义。候选可以共享读出参数，但必须能对同一接口产生不同响应；不再把旧selector的最终分数直接加回，作为绕过接口的主要决策路径。模型仍可保留必要原始量，不应为了制造“瓶颈”故意删除合法输入。

学习信号首先来自现有全池native winner。其接口梯度可写为

\[
\frac{\partial\ell_{\rm CE}}{\partial H}
=\sum_m(p_m-\mathbf1[Y=m])\frac{\partial u_m}{\partial H}.
\]

若某状态只给所有候选同一加性分数，该通路对选择没有作用。这个式子解释了差异响应的学习压力，**不证明终局标签足以识别真实区域成本或内部算法**。已有成本关系也可用作监督，但科学对照必须共享完整目标，不能一边换状态、一边换损失再将全部收益归给接口。

### 3.3 为什么值得优先，文献支持到哪里

它有三个同时成立的特点：确实改变表示单位；当前标签可定义完整判别训练；不必在query先调用真实求解器。相比后两条路线，它少依赖尚不存在的训练资产。其假说是端点耦合、跨区域连接和资源冲突的组合，比已经试过的局部短路径更接近不同部署方式的差异失败。**候选是否真的沿这些条件分化，仍待验证，不是本文已经发现的机制。**

[DiffPool第3节](https://arxiv.org/pdf/1806.08804)提供软分配后的节点与邻接聚合，适合作为“普通粗化”的近邻，而非接口提案的现成证明。[Neural Trees第5-6节](https://papers.nips.cc/paper/2021/file/ddf88ea64eaed0f3de5531ac964a0a1a-Paper.pdf)提供分解树和上下消息的组织思想。由此迁移到候选条件接口表，是本轮项目提案，不是论文已展示的selector。

**最大的结构反方是完整图并没有廉价的精确分隔。** 完整距离图树宽为`N-1`，不能借低树宽结果宣布这里的层级表示精确、高效。路线多次跨区、端点配对和资源历史可能使完整接口组合爆炸；少量端口与模板只能是近似。H-TSP用真实端点子问题求解及路线合并处理这一困难，但这已是求解流程，不能作为免费的前向替代。[H-TSP方法与Algorithm 1-2](https://www.microsoft.com/en-us/research/wp-content/uploads/2023/02/8643.PanX_.pdf)

更直接的历史反方是R92的32/8层粗图和R107的连通路径。两者没有支持“只要层级化或增加局部关系就能突破”。路线1的必要差异是条件对应跨尺度持续存在，不能只改聚类方式或节点数。R56也已有持久边状态，R63已有多轮候选节点状态，不宣称本轮首次引入持久关系。

现有主干也不是只看统计量：完整ATSP矩阵仍进入attention bias，候选与实例已有交互。这里提出更明确的组合偏好，不是证明旧网络完全丢失长程信息，更不是以人为削弱的旧模型作反方。

### 3.4 两层信息、代价与一个决定性对照

**现有信息层是正式保留的版本：**把接口解释为具有明确索引的判别潜状态，只用原始输入和已有监督学习。**授权扩展层不是偷偷加的保证：**若要将接口值解释为条件剩余成本、真实可行性或程序状态，需要相应子问题/过程标签；这将与主线三发生联系，不能再称同信息架构对照。

若共有`L_R`个区域、`P`个端口、`B`个资源条件、宽度`d`，单进单出表示的状态规模约为`O(L_R P^2 B d)`；多模板和枚举子签名组合会进一步增长。低秩或稀疏接合是近似，原始距离及跨区关系也仍可能平方增长。这里给的是计算对象的代价来源，不是GPU或训练预算承诺。

**决定性科学对照：条件保持 vs 条件塌缩。** 两个完整模型使用同一层级、输入、监督和候选决策路径；控制模型每次跨区传递前对边界条件聚合再广播，另一模型持续保存对应。两者均按各自结构训练，而不是推理时突然打乱强模型。参数与实际计算的差别应明示，内部控制之外还须比较完整参考策略。

若条件保持只提高TRAIN拟合、不能比塌缩控制带来有价值的全18改选，则削弱“该接口分解使相对优势更易学”的核心假说，结束这一个具体近似，而非自动加端口、层数和阶数。若它只降低成本而损失Top1，结论是目标取舍，不称共同突破。若成功，值得沿真实受益的组合条件理解，而不是直接宣布所有层级网络有效。

## 4. 主线二：从实例分类到候选响应函数学习

### 4.1 这不是再换一个ICL模型

目标不再只是学`X -> winner`的单行映射，而是学会利用一组结构和结果，推断“哪种变化使哪个固定候选相对受益”，再将该规律用于新实例。核心学习单位是有共同响应规律的实例族，而不是把原样本任意改名为meta-task。

两层提案必须分开：**冻结层改变整个条件学习系统，但不新增观察；授权强层增加成对、真实的候选响应，改变可学习的训练材料。** 本综合优先看重后者的科学判别价值。冻结层可以独立研究，却不能凭借相同的“函数学习”名称继承新语料的证据。

### 4.2 冻结层的完整架构：让支持数据参与形成计算规则

一个足够具体、不同于晚期检索修正的载体如下：

```text
训练资料：合法TRAIN图、任务/部署语义、全池已有结果
  -> 形成基础实例互斥的支持/查询任务
  -> 支持实例的图结构与候选响应先绑定成联合证据token
  -> 集合编码器形成函数状态 Omega_e
  -> query仅用输入选择/组合来源函数状态
  -> 函数状态逐层条件化query节点与关系更新
  -> 同一函数状态下比较全部合法候选
  -> query的native winner监督 -> 一个方法

部署：冻结参数 + 只读TRAIN支持库 + 新query原始输入
  -> 输入驱动的函数状态 -> query结构计算 -> 全池概率 -> argmax
```

这里的函数状态不是一个新求解器，也不在query之间在线更新。支持样本可以缓存输入表示；响应与结构的联合编码和查询推断规则则共同学习。不能把支持成本单独平均，再把几何差单独平均，最后只加一个分数修正，就声称实现了这条路线。

设环境`e`来自可信生成来源、可见条件或TRAIN内部发现的关系。支持集合`S_e`只含合法历史样本。用TRAIN确定的正尺度`s_t`构造中心化响应

\[
r_{im}=\frac{C_{im}-\overline C_i}{s_t},\qquad
\overline C_i=\frac1{|M_t|}\sum_{j\in M_t}C_{ij}.
\]

中心化保留同实例全部成本差，但不代替原生winner口径。一个实现性定义是

\[
z_{im}=J_\theta(E_\theta(X_i),d_m,r_{im},\mathbf1[Y_i=m]),\qquad
\Omega_e=A_\theta(\{z_{im}:(i,m)\in S_e\}),
\]
\[
\Omega_q=B_\theta(E_\theta(X_q),\{\Omega_e\},t_q),\qquad
H_q^{\ell+1}=T_\theta(H_q^\ell,\Omega_q,\chi_{t_q}),
\]
\[
\widehat p_q=\operatorname{softmax}_{M_{t_q}}
G_\theta(H_q^L,\Omega_q,\{d_m\}).
\]

`J`先绑定结构与响应，`A`将支持集压成若干函数状态，`B`仅由query输入选择和组合来源，`T`使函数状态介入结构计算而不只介入末端偏置。集合注意力、函数槽或条件算子是可选参数化，不宣称只有某一种正确；**不可退让的机制是支持响应影响query的结构推断，并用跨环境query训练这个推断器。** 每个候选缺失列须mask，同family不同checkpoint或部署不能强行当相同响应。

主训练目标是18题等权的episode查询原生CE，成本响应作为同一函数状态的监督对象。支持端允许历史标签，是已授权例外；query端的真实成本和winner只进入目标，不进入计算。形成任务关系、环境归属或支持集时，同样排除query及其base关联副本；不能在分组阶段先泄露答案，再声称前向没有标签。

为何可能迁移？假说不是“相似实例有相同winner”，而是**不同环境可以共享结构变化到相对响应的映射片段**。支持集提供该映射的证据，query层级计算再将它应用到新的结构组合。相比R47同题邻域的逐方法聚合、R97/98/100固定357维统计量上的冻结推断，本提案共同学习原始结构、函数状态和跨环境应用。相比R105，状态不只是由query生成的专家gate，而包含合法历史响应的条件证据。

这是可检验的归纳偏好，不是更大函数类的严格支配定理。如果最终退化成按N分桶、背winner比例或读取最近邻标签，它就没有兑现本路线的大改变。R47和完整TRAIN的ICL结果是很强的历史反方，不能仅靠“端到端”三个字消除。

### 4.3 02函数先验与04任务族：应合并，不能重复计票

[PFN第2-4节及Algorithm 1](https://arxiv.org/html/2112.10510v3)从指定先验抽取整个数据集，遮住query标签，学习该先验的后验预测；它不是从任意现实数据自动获得正确先验。[MLDG方法与Algorithm 1](https://homepages.inf.ed.ac.uk/thospeda/papers/li2017metaDG.pdf)则将一个源域更新对另一个源域的影响纳入训练。两者提供不同的训练分布构造方式，不是“用了meta-learning便会迁移”的共同实证。

对本项目，可以将当前环境episode看作经验性的响应规律集合，把新增成对响应看作进一步约束这一集合的数据。**不能把18题拆成大量随机episode，就称产生了大量独立函数。** 固定部署在不同环境中的响应往往仍是同一个函数的不同输入区域；“任务先验”在冻结层只是学习组织，不自动是可信的贝叶斯生成模型。

跨环境也不自动等于跨候选：一个新候选是未知响应列，仅有名称或family描述通常不能识别其排序。本轮保持当前池；若要新候选或新预算响应，需要对应TRAIN锚点或额外机制假设。MetaOD和OBOE虽研究性能矩阵迁移，但分别包含landmarker计算或新任务上的实际算法观察，不能将它们的“无需目标标签”误读为本项目的零query执行。[MetaOD第3节](https://arxiv.org/pdf/2009.10606v2)、[OBOE第3-4节](https://web.stanford.edu/~udell/doc/yang2019_oboe.pdf)

因此，02提供“学习推断规则”的框架，04提供经验任务和真实响应数据的来源；03对“只把联合终局密度改名为函数后验”的反对也成立。三者在这里不是互相抵消：本综合保留**结构化条件学习和训练单位改变**，不保留“换更大的生成密度即构成新范式”。

### 4.4 授权强层：用真实成对干预学习相对响应

令`X=G(U,z)`，`U`固定基础实例，`z`为可控制且语义清楚的生成因素。同一个`U`下构造合法的`z_0,z_1`，对所有当前合法候选保持同一部署契约，获得

\[
\Delta_{mn}(U;z_0,z_1)=
[C_m(G(U,z_1))-C_n(G(U,z_1))]
-[C_m(G(U,z_0))-C_n(G(U,z_0))].
\]

ASCII定义：`Delta_mn = pair_gap_after - pair_gap_before`。如果所有候选的成本共同增加同一量，这个信号为零。它直接询问变化对谁相对有利，而不是只询问新实例是否更难。这里的受控输入响应也不等于揭示了solver内部的唯一因果机制。

04给出的两个候选干预族具有具体语义：在合法前提下，保持几何、需求多重集和容量，改变需求与空间簇的对应；或保持窗宽分布与空间尺度，改变时间窗中心与位置的关联。它们改变的是资源与几何的耦合，不是简单将所有约束变紧。尚无证据证明某个现有候选因此系统受益，更不能预设干预一定引发winner翻转。

端到端训练可以继续使用前述条件函数系统，也可以先使用同一个不带上下文的响应载体；**语料假说不应被绑死在一套昂贵元学习架构上**。共同要求是训练模型预测输入变化引起的候选相对响应，并保留端点的全池响应和native winner锚点：

\[
\widehat\Delta_{mn}
=[\widehat R_m(X_1)-\widehat R_n(X_1)]
-[\widehat R_m(X_0)-\widehat R_n(X_0)].
\]

只学`Delta`无法确定绝对名次。只有差分而没有端点锚点的方案应拒绝。部署仍只有单个原始query，经学得的函数状态或响应表示，再由原生winner训练的分类读出选择一个方法；不读取其配对实例的答案，不在线求solver，不把预测平均成本的argmin冒充冠军概率决策。

式中`R_hat`处在原生成本差的尺度；若模型训练的是前述中心化响应，可取`R_hat_m = s_t * r_hat_m`。共同加性项在两两差中抵消，但不能把未经还原的标准化差分直接当作原生`Delta`。这不要求恢复共同成本基线，也不取消端点名次锚点。

**新winner必须有真实来源。** 已知组合问题的新最优解，或变换保持最优目标值，不等于固定近似候选的winner已知。需要授权后取得全合法池的原生成本、合法性与状态，或足以判定全池winner的严格证书。只运行两种方法不能得到全池标签；预测值、超时或缺失也不是成本真值。[Sound perturbation论文第3节及TSP方法](https://arxiv.org/html/2110.10942v2)支持构造可控问题变化，但不提供当前候选名次的免标注定理。

这与R73新输入上的教师伪标签、R95已有行的曝光重分配都不同；R77说明独立样本有有限价值，也没有证明这种成对监督会成功。新数据须另获授权、独立版本化、与冻结留出及其base关联隔离，不改现有评估分布。额外无标签输入只扩大`P(X)`的覆盖，不能替代真实相对响应。

### 4.5 最强反方与决定性科学对照

**冻结层的最强反方是独立响应规律不足。** 当前每题已有81k样本，任务族可能只是先验或样本密度；大条件推断器还可能比直接分类更难学。DomainBed的匹配比较和IRM的条件性反例提醒，跨域目标不天然优于强合并训练，也不应将真正改变winner的因素强制当作不变增强。[DomainBed所读早期稿第2-5节](https://arxiv.org/pdf/2007.01434)、[IRM风险第3-5节](https://arxiv.org/html/2010.05761v2)

冻结层对应的科学对照是：同一载体、支持量和行曝光，比较真实响应关系组织、保留输入标签配对但随机化任务连接的组织，以及普通合并训练。若真实连接不胜随机或合并，便不支持“跨任务响应关系提供了额外可迁移规律”；不能靠更多分桶继续认领该假说。有限冻结episode的成功也不自动成为未见分布或未见候选证据。

**授权强层的最强反方是干预只制造了特殊世界。** 即使能准确预测相对变化，也可能只改善专造的对抗或边界集合，不服务当前自然分布。对应的决定性对照是机制定向成对干预与同生成器家族、相近幅度和可比标注代价的随机合法成对干预，使用同一个下游学习器。先说明新基础实例上的响应预测，再看固定自然分布全18的完整策略后果；这是一个科学对比，不要求先实现精确VOI估计器。

两层对照是依信息选择的不同研究问题，不是一张必须全部跑完的矩阵。若新增语料只改善专造分布，应将结论限制为该场景鲁棒性；若相对响应基本不变，或定向构造不优于随机，则降低这组机制解释的优先级，而非自动十倍扩容。

资源主要来自支持集结构编码、函数状态读取，以及授权强层的合法生成和全池标注。朴素支持注意力可随支持数平方增长；缓存与压缩降低代价但也会丢失结构。不能把“全部81k上下文”称为免费。本综合仍将真实成对响应放在新增资料的首位，理由是信号直接约束目标差异，而不是已经知道它会带来更大涨点。

## 5. 主线三：让预训练得到的算法规则继续执行

### 5.1 迁移计算，不再只迁移向量

本路线学习的是节点、边和全局寄存器上的类型化状态转移。状态可能包含指针、活动集合、关系矩阵、资源或时间传播量；程序图中的结点可以是子问题或寄存器，不一定都是客户节点。关键不是多运行几轮，而是不同类型的状态如何组合，并将预测结果用于下一步。

```text
训练：合法TRAIN输入 + 另获授权的程序与状态标注
  -> 类型化输入/状态/输出接口
  -> 学习共享转移processor及程序专用接口
  -> 在真实TRAIN winner任务上学习候选条件读出

推理：原始query + 任务语义
  -> 自行初始化程序状态
  -> 处理器多步更新，反馈模型自己的预测
  -> 固定候选读取状态轨迹及必要原始量
  -> 全合法池的native winner分数 -> 一个方法
```

令`a`为训练程序，`m`为真实候选，二者不能混同：

\[
\widehat S^a_0=I_\theta(X,\chi_t,a),\qquad
\widehat S^a_{r+1}=P_{\theta,\tau_a}(\widehat S^a_r,E_\theta(X)),
\]
\[
L_{\rm proc}=\mathbb E_{X,a}\sum_{r,k}
\ell_k(D_k(\widehat S^a_r),S^a_{r,k}),\qquad
u_m=G_\psi(X,d_m,\{\widehat S^a_{0:T_a}\}_a).
\]

`k`区分标量、类别、指针等目标，`tau_a`规定状态接口或运算类型。过程预训练之后，原生winner监督继续塑造下游响应；最终处理器和状态反馈仍在部署图中。读出可以保留必需原始量，但不以旧完整selector分数作为替代状态路径；到底有没有利用执行能力，由科学对照裁决。

### 5.2 哪些计算规则才可能有用

值得研究的是任务约束相关的、可组合的运算载体，例如规定顺序下的资源包络组合，或非平凡兼容图中的约束传播。不能只凭熟悉的算法名字选择训练任务。完整欧氏图上，允许零对角时有

\[
\min_k(d_{ik}+d_{kj})=d_{ij}.
\]

所以最短路闭包没有替我们算出访问所有节点、访问次序或容量相容性。把Bellman-Ford准确率提高，不能自动补上固定候选相对错误。另一方面，给状态加入完整访问集合又可能逼近组合求解难度，不能宣称得到既精确又便宜的通用程序。

[GNNs are Dynamic Programmers第2-7节](https://proceedings.neurips.cc/paper_files/paper/2022/file/8248b1ded388fcdbbd121bcdfea3068c-Paper-Conference.pdf)支持从展开、计分、归约及运算载体理解神经计算。[CLRS第3节及4.1节](https://proceedings.mlr.press/v162/velickovic22a/velickovic22a.pdf)给出类型化probe与预测hint反馈；[Generalist Learner第3-5节](https://proceedings.mlr.press/v198/ibarz22a/ibarz22a.pdf)提供任务接口与共享处理器的学习组织。它们没有证明routing候选竞争可迁移，CLRS也没有覆盖当前NP-hard选择任务。

最接近的[Neural Algorithmic Reasoning for Combinatorial Optimisation第3-5.3节](https://proceedings.mlr.press/v231/georgiev24a/georgiev24a.pdf)研究从算法任务迁移到组合优化，但TSP下游有Concorde最优路线监督及解码；冻结迁移较差，多任务也非总优，沿最优路线构造pseudo-hint的尝试被弃用。这支持谨慎研究“可执行计算迁移”，不支持通用程序数量越多越好，更不支持直接预测本项目涨点。

### 5.3 与历史的实质差异及授权分层

R63的候选节点GRU已有递归，R107已有局部资源前缀，不能把“递推”或“资源”当首次。R61迁移保存路线监督后的encoder，R101拟合的是静态teacher节点向量；R94/106通过native表征融合和微调迁移知识。本路线的差异是**规定语义的状态监督、可复用的运算组织，以及下游持续执行**。如果最终只导出一个embedding，最重要的差异就消失了。

仅有终局winner/成本可以训练一种带类型偏好的潜状态机，却不能认证其等于规定算法。这个冻结版本可作为架构研究，但不代表已经完成本路线的核心预训练，也不作为默认首选。

强版本需要另获授权的过程资产：定义程序、合法输入、状态采样与监督来源；可先限于既有TRAIN，也可另议额外输入语料。这两种数据扩展不同，都没有在本轮执行。现有旧路线档案不等于当前全18、81k的完整过程库，更不等于所有候选的原生轨迹。

query阶段只读原始输入和模型状态，不能teacher-force真实中间状态，也不能使用教师决定的真实执行长度。CLRS原基线评估使用真实hint数量控制步数，这项条件不能照搬。推演长度应只由允许输入、固定有界规则或模型自身停机决定；PonderNet类停机机制只解决算多久，不解决算什么，不独立升格为第四主线。

### 5.4 为什么排第三，而非新增资料首选

算法状态转移比静态teacher向量更有解释力，也可能跨实例规模和组合方式迁移。但它离当前目标仍有两段距离：先学会选定程序，再学会这些程序状态怎样影响真实部署的相对误差。若程序主要刻画共同几何，下游不一定获得新的比较信号。成对原生响应虽更依赖标注，却直接观察后者，因此本综合不沿用02的最高排序。

这不是因新授权而降低科学地位，而是按**监督与目标之间的桥梁数量及可信度**排序。若未来有明确的任务相关状态，且其变化与真实候选误差相连接，这条路线的优先级可上升；无需等待区域接口先成功。反过来，不能只因公共程序在论文中能外推，就把大量程序库当作基础模型答案。

另一个强反方是：某个原语若可廉价精确计算，学习其近似未必合理。神经预训练的价值应在可迁移组合、摊销或后续适配，而不是把容易的算术做得更贵。状态规模、程序长度和全边交互决定代价，可能是`T * cost(P)`；若每候选分别模拟，还乘以候选数量。报告没有据参数量推算任何资源预算。

### 5.5 选择一个核心对照，而不是两套消融矩阵

01提议类型化转移对通用转移，02提议静态状态监督对连续过程监督。两者问的问题不同。本综合优先采用后者：**同一个最终递归选择器，比较从头学习、静态状态快照预训练、连续状态转移预训练。** 两个预训练臂接触同一组状态目标；快照从输入、程序及时间索引预测，转移臂反馈前步预测；共同下游标签、候选池和选型规则不变，训练计算差别明示。

这个对照首先回答“保留可执行过程是否比密集静态监督更有用”，比一开始争论哪种运算原语最佳更贴近本路线主张。它不完全隔离所有优化因素，也不以随机错标签制造必输控制。类型化对通用转移可以解释后续正结果，不在本轮另排一套必做实验。

若过程已能自回归执行，却不改善完整全18策略，则停止扩大该程序库来支持选择迁移的主张。若过程本身学不成，只能判当前表示和学习配方未兑现，不可宣告所有算法学习失败；但也不能以“还没彻底学会”为由无限追加数据和迭代。如果只降低成本而降低Top1，应按目标取舍报告。

## 6. 为什么不把其它专题建议全部留下

### 6.1 反向淘汰：是真的新推理，但不是本轮首要大表示

03的方案先编码图，再对每个候选子集计算淘汰概率，将完整排序的所有内部路径边缘化为冠军概率。它不等于Borda，也不是MAP排列的冠军；现有全池成本可以监督完整排序，无须新增过程标签。这个机制与R71的连续成本差密度、R111的静态家族分解确有不同。[Choosing to Rank第2节](https://arxiv.org/pdf/1809.05139v2)

但其主要持久状态是“哪些候选尚未淘汰”，图内部通常仍编码一次。因此它优先改变的是**冠军概率的参数化与推理组织**，而不是怎样获得可迁移的实例优势特征。`O(K*2^K)`的概率传播乃至更贵的子集交互说明它不便宜，却不能以计算量证明它更接近平台根因。

[Learning Rich Rankings第5.3节](https://papers.nips.cc/paper_files/paper/2020/file/6affee954d76859baa2800e1c49e2c5d-Paper.pdf)的相关位置似然收益并不在第一位；这不是Top1无效的定理，但提醒完整排序拟合不自动服务冠军。全池终局监督还不保证罕见子集状态有充分覆盖。**裁决：保留为次级决策架构，不列第四条主线，不把它说成只有loss变化。** 若未来有具体证据表明主要缺口在集合条件冠军建模，可以重新提高它的优先级；本轮没有这项项目证据。

### 6.2 原生结果模拟器：真正的大对象，但不等于通用算法预训练

03的强版本预测各固定候选实际会返回的结构，再经原生目标评价形成选择。这比R71终局密度更彻底，也比只加结构aux更强。但它不是主线三的自然别名：主线三学习已定义程序的可复用计算，模拟器必须学准**当前checkpoint、解码、增广和repair共同造成的具体结果差异**。一般过程能力提升，不证明这种行为复制已经成立。

R55已尝试结构计费差瓶颈且近乎未学成；结构间微小差异恰可能决定winner。把全池完整结构恢复成必经路径，会增加监督缺口、组合相容性和误差传播。DIFUSCO提供解变量生成与解码机制，但“生成好解”不是“模拟某个固定候选会返回的解”。[DIFUSCO第3节](https://arxiv.org/pdf/2302.08224)

还须修正一个容易过度的边界说法：**模型内部预测多个结构、最后只执行一个原候选，并不自动变成真实多solver组合。** 这可以仍是单方法选择，只是选择计算可能很昂贵，并需说明结构评价/修复是否包含另行授权的优化。真正改变任务的是实际运行多个原生候选后择优，或直接返回生成的新解。不能因为称为“模拟器”而隐藏计算，也不能仅因有多个内部状态便误判任务已变。

**裁决：保留为条件性远期对象，不与主线三合并获得未经支持的强主张，也不列当前前三主线。** 只有具备候选特定结构监督、明确的行为误差目标和有意义的选择开销，才值得重新讨论；本轮没有确认这些资产齐备。

### 6.3 其余降级项

| 方向 | 本轮裁决 | 实质理由及保留边界 |
| --- | --- | --- |
| 纯输入大预训练 | 不列主线 | MAE/JEPA类可以重建整个骨干，历史也未穷尽；但坐标到距离、完全图连边等任务可能平凡，额外`P(X)`不识别固定候选差异。需要任务相关的表示理由，不能靠规模命名。 |
| 更大联合成本生成器 | 不列主线 | R71已有联合密度和冠军积分，R47/97/98/100已有历史响应。只换flow、diffusion或“函数后验”名称，缺少新的关键对象；更多采样主要减少模型积分误差。 |
| 完整松弛/原始-对偶选择主干 | 暂不优先 | 全局变量、乘子和约束残差确是新状态；但真实query优化探测需另授权，共同下界不决定候选误差差。潜向量版又不能继承优化证书。 |

输入预训练的方法边界见[GraphMAE第3节](https://arxiv.org/pdf/2205.10803)、[I-JEPA第3节](https://arxiv.org/html/2301.08243v3)与专题02。优化状态的计算对象见[LP与MPNN论文第2-4节](https://proceedings.mlr.press/v238/qian24a/qian24a.pdf)，但模拟IPM的构造或学习代理不等于任意短网络自动满足可行性、对偶证书或候选选择收益。以上不是永远否定整个领域，而是本次有理由不将其列为优先路线。

## 7. 一张有限的科研路线图

### 7.1 先选要回答的问题，不把三个系统全部叠起来

```text
仅讨论当前冻结信息
  -> 首选：条件接口是否使全池相对优势更容易学习？                 [主线1]
  -> 次选独立问题：真实响应任务关系是否超越检索/合并训练？          [主线2冻结层]

愿意另议新增训练资料，但不增加query观察
  -> 优先：哪些受控变化真的改变候选相对响应，并可迁移到自然分布？  [主线2授权层]
  -> 长线：哪些可执行规则能迁移成选择能力，而不仅是程序准确率？    [主线3]

只有出现正证据以后，才讨论互补组合
  -> 响应语料可以训练接口网络
  -> 程序状态可以赋予部分接口更强监督
  -> 不预设三者相加必然更强，也不要求某一路线成功才允许研究另一条
```

这是问题依赖图，不是实施顺序表、训练命令或预算。特别是新增成对语料的价值，可以用同一个较简单载体研究，不必先建成函数基础模型；区域接口也不必等算法语料获批。避免把三个有风险的假说绑成一项无法解释的巨型工程，是保持宏观探索清晰，而不是退回小修补。

### 7.2 结果应该怎样改变下一步判断

| 科学结果 | 支持或削弱的主张 | 后续研究取舍 |
| --- | --- | --- |
| 条件保持优于塌缩控制，且完整策略有净价值 | 支持该接口组织提高可学习性，不证明精确组合推理 | 优先理解跨区条件如何引发候选差异，再讨论与响应监督结合 |
| 条件状态更丰富，但只有TRAIN或辅助收益 | 削弱当前接口近似与监督之间的桥梁 | 不自动增加端口/阶数；可独立转向数据响应或过程学习问题 |
| 真实任务连接优于随机及合并训练 | 支持经验响应规律的跨环境利用 | 保留函数状态组织；仍不声称任意未见函数或新候选可迁移 |
| 成对响应能预测，但自然全18没有净价值 | 支持特定干预场景学习，不支持当前分布突破 | 限定为该场景鲁棒性，不凭差分loss继续扩充同一语料 |
| 程序自执行改善，选择却不优于静态状态监督 | 反对“执行能力足以转成当前候选优势”的具体桥梁 | 结束该程序库扩张，不靠更多程序或停机技巧补叙事 |
| 任一路线Top1与成本方向不一致 | 存在目标取舍，而非共同改进 | 按既定主目标解释；不事后改变推理规则制造两项都赢 |

每个阴性约束的是完整的对象、监督和决策路径，不是一个无限大的标题类别。每个阳性也只支持所比较的机制，不自动转成可保证的后续涨点。全18有价值不要求每个问题、每项指标都严格上升，但损益的来源必须看得见。

### 7.3 R109/R111的位置

本轮没有检查它们的实时状态，也不把此前在途信息写成已完成阴性。若其最终结果对候选私有计算或族条件学习有正证据，应更新完整参考策略及对已有优势的理解；若为负，应降低相应共享方式和树形决策配方的优先级。**两种结果都不自动证明区域接口、响应函数或可执行规则成立或失败。** 它们照原安排运行，本稿不以等待它们为科研结论。

## 8. 何种收益才与用户目标一致

以同一完整模型、同一合法池和一个最终方法为单位。设参考决策为`d0`、新决策为`d`，对每题分别计数：

\[
\operatorname{Recover}=P(d=Y,\ d_0\ne Y),\qquad
\operatorname{Harm}=P(d_0=Y,\ d\ne Y),
\]
\[
\Delta\operatorname{Top1}=\operatorname{Recover}-\operatorname{Harm}.
\]

同时报告新选中某目标方法但该方法并非winner的**新误选**。它包含双方都错的改选，因此不能以`Harm`或Top1变化代替。某方法被选得更多、接口更准确、过程更像教师、排序NLL更低，都不是这个净价值的替代物。

保留全18与每题Top1、mean_cost、TRAIN拟合SBS、Oracle、vs_SBS、vs_Oracle及逐实例actual regret；ALL沿用逐题等权，跨题raw cost不当成统一物理损失。均值比和逐实例regret不混同。真实恢复既看固定目标，也看清单外错误，不能以一个候选对代表全池。无需在本文再建立一长串预检或消融网格。

已有TEST/LIB参与了多轮研发，不能称完全盲测。将来若开展研究，仍应由VAL确定唯一checkpoint和推理规则后报告固定模型的完整TEST/LIB；这不是现在新建划分或开展实验的指令。答案感知union只是一组已知预测的覆盖统计，不是可部署上限，也不能成为三条路线的涨点承诺。
