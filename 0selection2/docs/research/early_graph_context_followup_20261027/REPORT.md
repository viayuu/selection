## 1. 先给结论

**固定 solver 函数下，历史 TRAIN 上下文还有科学对象吗？有，但应称为固定任务上的条件化非参数预测，而非凭 episode 产生新函数的元学习。** 一个有限参数模型未必充分保留训练资料；推理时重新访问合法历史样本，可以改变有限样本下的归纳偏置与计算分配。NPT 和 TabR 为这种学习提供直接方法依据。它们不证明本项目必须使用上下文，也不证明早期介入优于强晚期介入。

**与 R47/R97/R98/R100/R101 实质不同的对象是什么？** 不是增加记忆量、改用成本标签或把整图向量放进 Transformer，而是：**在 query 内部关系更新和压缩之前，以“支持图局部结构及其整图优势标签的绑定”为条件，形成候选相关的 query 节点间消息。** 原始图的距离、方向和约束并不被改写；被条件化的是模型计算哪些关系、如何传递信息。

**现在是否有足够扎实的正面推荐？没有。** 本轮实际阅读九篇原始论文的方法与相关实验，其中六篇超出上一报告第7节的 TNP/PRODIGY/CAGML；六篇中 TabR 是 R47 已有依据，不计作新发现。五篇额外工作为 NPT、Graph Matching Networks、EGNN、CrossTransformers、TADAM。它们分别支持固定任务上下文、跨图软匹配或条件表示，但没有一篇同时验证：固定 solver 性能映射、独立无文本整图、整图成本监督、局部关系早期条件化、全18题合法池。

因此，本稿只保留一个**可反驳的高风险科学备选**，不建议因调研完成而默认开跑，也不以“旧方向还没穷尽”为继续理由。

## 2. 固定函数与 episode：到底能学到什么？

### 2.1 函数固定，不等于有限模型已经学会函数

对问题 p，记冻结候选池为 K_p，部署条件固定后的候选成本映射为：

```text
F_p(G) = (C_p,k(G) : k in K_p)
S_q subset of historical TRAIN_p, excluding base(q)
prediction = f_theta(G_q, S_q, p, K_p)
```

这里将已知运行条件纳入 G 或 p；若还有未观察的执行随机性，不能凭本稿将其大小定为零，也不能用它解释全部错误。native winner 是原数据提供的监督口径，不由低精度成本重新生成。

在确定性设定中，给定完整 G 和真实 F_p，query 答案已经确定，历史支持集不会提高这个条件下的信息论上限。但学习者只有有限资料和有限参数，不拥有 F_p 的精确描述。模型参数压缩之外再保留 TRAIN，可以提供尚未被参数有效利用的经验信息。这是非参数估计的理由，不需要假定部署时出现一个新 solver 函数。

这一点有直接而非类比式依据：NPT 把单个数据集的特征与已知标签共同作为输入，并在预测位置遮蔽标签；其 §3 明确区分自身与依赖多个函数实现的 Neural Processes。TabR 也在每个普通监督数据集上训练检索与预测模块，不要求先生成新任务族。[NPT，§2–3](https://papers.nips.cc/paper/2021/file/f1507aba9fc82ffa7cc7373c58f8a613-Paper.pdf)；[TabR，§3.1–3.2](https://proceedings.iclr.cc/paper_files/paper/2024/file/4ef594af0d9a519db8fb292452c461fa-Paper-Conference.pdf)

### 2.2 任意分 episode 不会制造新的性能函数

把同一个冻结 TRAIN 分为支持部分和监督 query，可以训练“在缺少当前答案时使用其它记录”的运算。变化的是可见证据和被预测实例，不是 F_p。重复分组不会增加独立原生标签，也不会自动产生跨函数泛化能力；相同基础实例反复出现在不同组中更不能计为独立证据。

这类训练仍可能有用：它让前向计算适应不同支持集，并把当前标签限制在监督端。但同一个目标也允许网络忽略支持集，仅学习普通映射。没有函数变化意味着**不存在必须根据上下文辨认未知任务的压力**，而不是“上下文在逻辑上必然无效”。固定标签语义下随机重命名 solver，最多改变编码或制造辅助任务，不会改变各 solver 的真实成本函数。

whole18 确实包含不同约束和候选池，但这些是已知、固定的18个问题，不是从任意 episode 获得的无限新函数。不能从有限题型共享推导出未见 solver、未见预算或未见场景适应能力。本稿也不要求新增场景或重新采集响应。

### 2.3 六个概念不可互换

| 对象 | 推理时实际发生什么 | 本项目中不能冒认的内容 |
| --- | --- | --- |
| 固定函数非参数学习 | 从相同 TRAIN 记录辅助预测新实例 | 不等于新函数适应，也不等于在线学习 |
| Episodic meta-learning | 用不同任务中的支持证据识别任务规律 | 任意划分固定数据不提供同等任务变化 |
| Learned similarity | 学习何种实例或局部模式应相互比较 | 相似不保证 winner 相同，训练用标签不等于推理标签条件化 |
| Label-conditioned representation | 推理表示依赖支持输入与标签的绑定 | 可以只发生在整图层，未必影响图内关系 |
| Early graph conditioning | 标签绑定影响 query 图内消息及其后续结构组合 | “早”相对图内计算定义，不以模块名称或网络层号定义 |
| Late context | query 先独立形成结构表示，再与支持信息联合判别 | 不必是简单投票；可以保留节点/边并进行强局部匹配 |

## 4. 原始论文真正支持到哪里？

### 4.1 NPT：固定数据集上下文可以被学习，但不能借用它的复制答案实验

NPT 将标签作为属性，与特征一同嵌入，交替进行跨样本注意力和样本内属性注意力；被预测标签遮蔽。其普通监督实验涵盖十个 UCI 数据集，且 §4.3 检查模型是否依赖其它记录：破坏这些记录会损害部分任务，但有些任务几乎不受影响。它因此支持“固定任务仍可学习支持集运算”，不支持“上下文必有价值”。

最需剥离的是 §4.2：作者刻意提供带完整答案的重复行，验证 lookup 能力。那是构造实验，不是本文允许的泛化证据；本项目 query 及同 base 副本都必须排除。NPT 的各列还有共享语义，而独立路由图的节点没有天然列对齐。把每图第 i 个节点强行当作同一属性，不能算直接迁移。[NPT，NeurIPS 2021，§2.1–2.6、§3、§4.1–4.3](https://papers.nips.cc/paper/2021/file/f1507aba9fc82ffa7cc7373c58f8a613-Paper.pdf)

### 4.2 TabR：晚期条件化本身可以很强

TabR 在独立 encoder 后加入检索分支，使用共享 key 的距离，以及“标签值表示加 query-key 差修正”；这正是 R47 的重要原始依据，不是新的算法空白。§4.1 的比较中，其结果整体优于包含 NPT 在内的旧检索模型，但并非每个数据集都受益。

因此，不能把 NPT 的跨样本深交互解释为天然优于晚期检索。附录 B 还明确讨论了相关样本检索与真实部署不一致的风险，支持本项目的 base 排除边界。其表格实验不证明图压缩何时损失信息，却规定了反方应有的强度。[TabR，ICLR 2024，§3.2 式(5)、§4.1 表3、附录 B](https://proceedings.iclr.cc/paper_files/paper/2024/file/4ef594af0d9a519db8fb292452c461fa-Paper-Conference.pdf)

### 4.3 Graph Matching Networks：跨图交互能发生在节点更新内，但原文不是标签条件化

GMN 将跨图注意力得到的匹配差异加入每轮节点更新，随后才汇聚整图；不需要给定一一节点对应。§4.1–4.2 的图编辑与二进制控制流图实验比较了独立图 embedding 和联合匹配。§4.3 还加入整图向量拼接后用 MLP 判别的 Siamese 对照，GMN 仍更好；但该反方没有保留节点/边供晚期局部匹配，尚非本稿要求的最强控制。

限制同样直接：其标签用于训练图对/三元组相似度，不是推理时给支持图绑定 solver 成本；控制流图正例还具有同一程序函数的语义来源。独立路由实例没有这样的已知同源性。它提供的是**可学习软对应的计算形式**，不是几何对应会保留候选优势的证据；原文也指出配对计算不能直接替代可预计算的检索索引。[GMN，ICML 2019，§3.2–3.3、§4.1–4.3、§5](https://proceedings.mlr.press/v97/li19d/li19d.pdf)

### 4.4 EGNN：标签确实改变关系更新，但其“节点”是整幅图像

EGNN 以支持样本是否同类初始化边的两通道标签，未知关系初始化为中性值，再交替更新节点和边。它确实不只在最后传播标签。但图中的每个节点是已由 CNN 编码的**整幅图像**，不是图像内部局部部件，更不是独立路由图内部客户节点。

miniImageNet 表1把非传导设置的 66.85 与多 query 联合推理的 76.37 分开报告；不能拿后一数值当独立 query 条件下的增益。训练/测试类别也分离。原文证明标签能进入样本间关系更新，未证明一个整图 winner 能合理标注该图各条边。[EGNN，CVPR 2019；实际读取 arXiv v1，§3.1–3.3、§4.1–4.5](https://arxiv.org/html/1905.01436v1)

### 4.5 CrossTransformers：最重要的强晚期对照依据

该方法保留 CNN 的空间特征，而非先全局池化；在每个支持类别内，用 query 局部特征构造软对应和 query-aligned prototype，再汇总距离。标签通过支持集分组进入比较，但 query 的 CNN 主干并没有先被这些标签改写。因此，**“使用局部信息、无硬节点对应、支持标签参与”三点加起来仍不等于早期图内条件化。**

§4.3 的 Meta-Dataset 实验支持局部匹配的价值，也报告纹理数据 DTD 较不适配；增加全局分类信息能改善 DTD，却牺牲其它数据集。其 SimCLR episodes 另含同一图像的增强视图，不能直接转成本项目有标签的同 base 支持。本文只借它定义强晚期读出，不移植数据生成方式。[CrossTransformers，NeurIPS 2020，§3.1–3.2、§4.1–4.3、表2](https://papers.neurips.cc/paper_files/paper/2020/file/fa28c6cdf8dd6f41a657c3d7caa5c709-Paper.pdf)

### 4.6 TADAM：“条件化得早”也不保证保留输入与标签的绑定

TADAM 先将类原型求均值作为任务表示，再生成卷积层的缩放/平移参数，重新编码支持和 query。它是货真价实的早期特征条件化先例，但不是细粒度跨图结构匹配。其 §3.4 还报告，无辅助共同训练时，task conditioning 本身没有带来改善。

从 §2.2 的公式可进一步推出一个本稿的观察：**在各类等样本数时，类均值再求均值等于全部支持 embedding 的均值。** 仅在同一支持集合内重新分配保持等计数的标签，不改变这一 task summary。因此，早期 FiLM 不能自动当作标签与结构绑定的证据；分类读出使用标签与 task summary 保留绑定，是两件事。此代数观察不是原文额外实验，也不否定更丰富条件器。[TADAM，NeurIPS 2018，§2.2–2.4、§3.1/3.3–3.4](https://papers.nips.cc/paper_files/paper/2018/file/66808e327dc79d135ba18e051673d906-Paper.pdf)

### 4.7 对既有三篇的实质性收紧

**TNP：函数族假设是真实的，不应省略。** §2.1 从函数分布抽取训练和未见测试函数；§3.1 绑定输入与输出并设置预测掩码。wheel bandit 则改变隐藏参数 delta，并在部署过程中取得被选动作的奖励。它既不是固定 TRAIN 的一次性选择，也不是任意 episode 自动成为新函数。这里只保留成对绑定与可见信息约束，不借用在线反馈或联合 target 的真实标签。[TNP，ICML 2022；实际读取 arXiv v2，§2.1、§3.1、§4.3](https://arxiv.org/html/2207.04179v2)

**PRODIGY：prompt graph 不等于标签先于原图内部表示。** §3.1 明确先在每个 data graph 上独立消息传递，再读出单个表示，之后才在 task graph 上传递标签信息；原文提出可以多轮交流，但所述路径不能直接认证支持标签已改变独立整图的早期内部编码。实验主要是共享源图上的节点/关系分类。把每个路由图压成一个 data node 后复用它，仍可能只是强晚期上下文。[PRODIGY，NeurIPS 2023，§2.2–3.2、§4.1–4.4](https://proceedings.neurips.cc/paper_files/paper/2023/file/34dce0dc3121951dd0399ba02c0f0d06-Paper-Conference.pdf)

**CAGML：结构有用，不等于支持标签驱动了结构检索。** §3.3 式(4)的检索使用节点特征，式(5)形成结构表示；§3.4 式(7)再将实例表示与标签表示拼接。因而不能仅凭其结构模块把效果归因为“标签先进入结构形成”。实验依赖 PLM 文本特征，表3删除语义残差显著受损，结论把无文本图留作未来工作。这比泛称“图 ICL 已经有效”更能约束迁移。[CAGML，AAAI 2026，§3.2–3.4、§4.5、§5](https://ojs.aaai.org/index.php/AAAI/article/download/38511/42473)

### 4.8 证据链尚未闭合

| 必须成立的环节 | 本轮最相关来源 | 仍缺的部分 |
| --- | --- | --- |
| 单个固定任务能学习访问历史标签 | NPT、TabR | 本项目是否仍有参数外可利用的优势信息 |
| 无硬节点对应时能联合计算局部相似性 | GMN、CrossTransformers | 相似性是否与全池相对成本一致 |

| 早期图内条件化比强晚期局部读出更有价值 | 没有直接覆盖本设定的已读证据 | whole18 中最关键、仍待证实的一环 |

## 5. 唯一主科学机制：历史优势绑定的局部关系条件化

### 5.1 研究对象，而非一种新的函数族

**假说：有限模型可能过早把对相对优势有用的关系组合压缩掉；合法历史支持图的成本画像，能够在压缩之前指导 query 对这些关系的计算。** 这只是一种数据条件化归纳偏置，不新增 query 答案、solver 权重或执行轨迹。

支持记录保留完整绑定：`(G_j, native_winner_j, r_j, legal_pool_j)`，其中 `r_j` 是既有合法池中的完整相对成本向量。不能只给每个 winner 类求平均，也不能让所有成本同一个常数的易例与决定精细胜负的样本仅按频数累加。后一句是所求科学对象的要求，不是拟定新的采样规则。

一个足以界定对象的抽象表达是：

```text
t_q,ab = InputRelation(G_q, a -> b, p)
t_j,uv = InputRelation(G_j, u -> v, p)
b_j    = Bind(native_winner_j, full_r_j, solver_IDs, legal_mask_j)

m_q,ab,k = Aggregate_j [ pi_q,ab,j,k *
             Aggregate_uv [ alpha_q,ab,j,uv,k * V(t_j,uv, b_j, k) ] ]

e_q,ab,k = Update(t_q,ab, m_q,ab,k)
h_q,a,k  = Propagate(input_q,a, {e_q,ab,k, input_q,b}_b)
scores   = Readout({h_q,a,k, e_q,ab,k}, legal_pool_p)
```

`alpha` 由 query 关系、支持关系及其绑定信息共同确定，`pi` 保留支持图这一记录单位；二者只是软对应的抽象权重，并非规定网络、邻居数或实现方案。关键是 `b_j` 在 `Update/Propagate` 前进入，且不同 query 关系可以接收不同消息。仅把同一成本摘要广播给所有节点，再在末尾加 residual，不足以证明这一强机制已经实现。

它没有把图级成本分解成已知边级真值。训练时能提供的直接监督仍是 TRAIN query 的合法标签/成本，query 自身结果只用于计算监督，不能回流为前向条件。模型可能学到潜在信用分配，也可能完全学不到；注意力权重不能被解释为某条边造成某 solver 失败的已证实因果贡献。

### 5.2 没有自然节点对应，怎样传递信息？

跨图应比较**关系的角色与属性**，而不是索引。支持图中某条有向关系的长度、方向角色、需求、时间约束等输入描述，可以与 query 中具有相应语义的关系软匹配；不要求两个图有同样节点数或一一映射。信息来自“何种局部关系出现在怎样的整图优势画像中”，不是“支持节点7对应 query 节点7”。

同一支持图的多个局部关系共享一个整图标签，不能把它们当作多份独立监督，也不能因为支持图节点更多便自动获得更多证据权重。局部关系还必须保留其图内上下文与约束身份，否则来自完全不同全局结构的相似短边会被误当成同一种优势证据。

物理节点角色需要保留，例如 depot 与普通客户不同、ATSP 出发与到达不同。若原生部署对输入顺序敏感，该顺序属于各自图内的已知输入条件；这既不授权跨图按索引硬对齐，也不允许无证据假设所有 solver 对重排或坐标变换具有标签不变性。base 排除是防泄漏规则，不是标签不变性定理。

### 5.3 whole18 是对象的一部分

| 输入类型 | 条件算子需要尊重的事实 | 不可偷换成 |
| --- | --- | --- |
| TSP | 图内几何与原生输入角色；全合法候选竞争 | 只识别 LEHD/DIFUSCO 的局部专家 |
| ATSP | 有向矩阵及 FROM/TO 的非对称关系 | 对称距离或按节点编号匹配 |
| CVRP 与15种变体 | depot、容量、开放路径、B/L/TW 等已知约束及其组合 | 仅 ReLD 两方法对决，或把其它问题当附带验证 |

同题合法 TRAIN 支持已经足以定义该对象，无须假造跨题节点对应。跨题共享若存在，只能共享有明确定义的输入角色和运算，不抹去任务条件。每题仍输出全部合法候选的选择，保留八个 B 问题的删除规则、单一 `reld_mt` 与 native winner 口径，不恢复 RELD_MTL 或已删方法。

无论是否使用上述抽象形式，**新意仅在既有项目尚未等价覆盖的条件计算位置**，不是宣称这些构件首次发表于学术界。若实际对象最终变成整图最近邻、全局 FiLM 或固定统计 ICL，就应按真实机制命名，不借用本稿的强解释。

## 6. 唯一最强反驳：不存在可迁移的“局部结构到优势”规律

最强反方不是“函数不变化，所以任何记忆都无用”，而是：**在这个固定函数上，整图优势也许根本不能通过跨实例局部对应来稳定归纳。** 一组相似的几何或资源关系，可能在不同全局组合中触发完全不同的解码、增广和后处理分叉；整图成本只给出最终结果，没有告诉模型是哪段关系导致差异。

这一反驳同时解释几种表面上不同的失败：胜负在近并列边界上不平滑；结构相似但 solver 相对优劣不同；支持信息只重复总体难度或常见 winner 先验；大量局部 token 仍被一个整图标签错误归因。它们是同一个识别缺口的不同表现，不是要求逐项开实验的清单。

R47 已让检索与标签聚合接受监督，R97 又消除了“上下文太少”的简单借口。新的图内条件化虽然不等价，但还必须说明它为什么能从同一批弱图级监督中学出更可靠的关系。将历史成本广播得更早，甚至可能更容易污染全部节点表示，让参数和外部记忆重复利用同一先验，而不是获得新的区分能力。

完整成本向量比单一 winner 更丰富，但不自动修复局部信用分配；平滑预测平均 gap 也不保证恢复 native Top1。反过来，强晚期模型如果保留足够细节，可能已经能表示同样的条件决策。早期算子没有普遍表达能力优势，更没有已证明的样本效率界。本稿没有证据断言瓶颈确实是早期压缩。

如果真正有用的规律只能通过 query 的实际路线、成本、在线奖励或同 base 答案才能确定，本机制在当前权限下就不成立。不能为挽救科学叙述而突破知识边界。

## 7. 唯一决定性科学对照：早期图内条件化对强晚期局部读出

只比较一个问题：**在相同合法支持信息下，标签参与 query 图内关系形成，是否比独立形成关系后再联合读取更有价值？**

强晚期控制必须拥有同一批支持图、完整成本向量、native winner、候选身份与合法 mask，并以同样的原始 query 输入学习表示。其图 encoder 可以接受最终任务损失的端到端训练；“推理时编码不依赖当前支持标签”不等于“冻结或不训练 encoder”。

更重要的是，晚期控制不能被人为限制成一个均值向量或固定统计分类器。它应能够保留节点、有向边及多尺度输入信息，通过训练过的 query-support 局部匹配、标签绑定与联合候选读出完成判别。CrossTransformers 提供这种强读出的原始依据；TabR 则提醒，成本/标签值与 query-reference 差异也不能从反方中删掉。这里借鉴对照原则，不要求机械拼接两篇架构。

科学分界是：早期侧的支持标签进入后，还参与 query 内节点间消息和关系组合；晚期侧的 query 图内关系先独立形成，支持信息仅用于随后充分强的匹配与决策，不回写图内结构计算。**晚期不是低分辨率的同义词。** 若只给早期侧保留局部原始信息，而让晚期侧先丢掉这些信息，观察到的差异无法归因于标签介入时机。

两者的支持来源、可见信息和表达能力必须认真对齐；不同计算位置未必能做到完全相同的计算量，因此不能在没有具体设计前宣称这是已经实现的严格单因素比较。本稿只定义科学对照，所有有限设计、可行性判断和操作决定交给 Sol。

**结论如何被推翻？** 若早期侧不优于这类强晚期控制，或仅改变方法出场比例而未改善真实命中与误选代价，则本次机制没有获得支持，不应自动用更多 episode 或更大支持集续命。若两者都改善，只能首先说明更强图上下文有用，不能把共同收益归因于早期介入。

若早期侧在 whole18 同口径联合目标上确有可归因的改善，最强可支持结论仍只是：在这一冻结数据与合法候选设定下，支持条件化的图内计算是一种有效的有限模型归纳偏置。不能由此宣布学到新函数、恢复真实因果边贡献、解决所有零选择或获得未知场景泛化能力。仅 TSP 或某个 ReLD 对上的收益不足以兑现此命题。

## 8. 知识来源、失败边界与交接

**可用知识：** query 的原始输入与已知部署条件；冻结 TRAIN 的历史特征、native winner 和完整合法相对成本向量。TRAIN query 必须排除自身及同 base 关联副本；任何 query 不得通过支持集间接取得自身答案。VAL/TEST/LIB 标签、查询路线/成本/求解状态均不能进入上下文。不使用文本编码器、在线奖励、测试标签适应或未授权原生求解。R58 修复继续延后。

**证据层级：** 论文方法与实验为本轮直接访问的一手材料；历史实验解释只来自列明的项目文档和限定的数据流阅读，不构成复核认证；第5节是本稿提出的待证假说；第7节是科学识别问题，不是实验协议。历史 TEST 已参与研发，不因改用上下文便重新变成盲测。
